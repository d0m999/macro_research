# Sector & Competitive Overview

同一研究对象的两个切入角：**行业模式**自上而下（市场边界 → 规模/增长 → 价值链 → 行业结构 → 监管 → 主题），**对标模式**以时点公司对同业（peer universe → 证据矩阵 → 定位 → 白空间）。两者共用同一套来源与可比性规则；产出可以是研究 memo、表格或 deck，以用户指定格式为准。

## 必读契约

- 来源合规与数据源路由遵循 [`../../PUBLIC-SOURCE-POLICY.md`](../../PUBLIC-SOURCE-POLICY.md)（含路由登记表 [`../../data-sources.jsonl`](../../data-sources.jsonl)，无匹配时 fail-closed）。
- 创建或修改 Office 产物前读取 [`../../CODEX-EXECUTION-POLICY.md`](../../CODEX-EXECUTION-POLICY.md)；验证器状态与限制按其口径披露。
- 需要市场地图或框架选择时读取 [`references/frameworks.md`](references/frameworks.md)。
- 需要交易表、情景表或 slide schema 时读取 [`references/schemas.md`](references/schemas.md)。

## 模式判别

- **行业模式**：问题指向行业/板块本身（边界、规模、格局、趋势、主题）。从顶部切入。
- **对标模式**：用户已给定时点公司，要它和同行比（强弱、差异、护城河、白空间）。从公司切入。
- 同一任务两者都要时，行业模式先定边界和 peer 池，对标模式在该池内建证据矩阵；不得把两套 peer 纳入标准混用。

## 工作流

### 行业模式

1. **定义范围**：行业/子行业、用途（客户报告/内部研究/路演材料/想法生成）、深度（概览 5–10 页或深挖 20–30 页）、角度（中性描述或主题 thesis）、universe（只上市公司或含私营）。
2. **市场概览**：TAM 带方法与来源；历史 5 年 CAGR；预测增速只取公开来源或标 `MODEL_DERIVED` 的情景；细分结构、集中度（前五份额只在有来源时给）、价值链、商业模式、进入壁垒。
3. **关键趋势与驱动**：3–5 个长期顺风、逆风与风险、技术颠覆向量、监管动向、M&A 与整合。
4. **估值背景**：板块倍数（当前与历史区间，来自已验证公开价格与 filings）、溢价/折价驱动、近期交易倍数（官方公告/filings/监管记录）、与大盘比较；不可得标 `SOURCE_UNAVAILABLE`。
5. **投资含义**：风险回报最优处、可表达的主题、板块内多空争论、可能改变叙事的催化剂。
6. **输出**：Word/PPT（市场概览、竞争地图、公司对比表、估值摘要、关键图表）+ Excel 附录。

### 对标模式

1. **定义问题**：目标公司、行业边界、地区、期间、受众、决策问题、输出格式。用户要求完整任务时直接形成合理结构；只有这些选择会实质改变结论且无法推断时才暂停。
2. **建立 peer universe**：从发行人 filings/IR、监管、政府、交易所和可核验协会资料识别直接、邻近与潜在竞争者；记录纳入/排除理由。
3. **建立证据矩阵**：按产品、客户、地域、渠道、规模、增长、盈利、技术、监管等维度收集同口径事实；每个数字带 source record，缺失保持 `SOURCE_UNAVAILABLE`。
4. **分析定位**：区分事实、管理层陈述和分析推断；识别可持续优势、弱点、白空间、替代风险与可能反应。
5. **形成输出**：用少量清晰图表表达一项主要结论；矩阵轴、权重或评分说明选择理由，金融阈值来自公开同业数据、用户输入或标 `MODEL_DERIVED` 的情景。
6. **验证**：核对公司/期间/单位、事实与叙事一致性、图表来源、关键数字跨页一致性和 artifact 限制。

## 完成条件

- 范围、深度、角度和 universe 与用户要求一致；每个市场规模、份额、增速、倍数和交易数字指向本次打开的来源及方法，不可达来源替换为 `SOURCE_UNAVAILABLE` 或标 `MODEL_DERIVED` 情景。
- peer universe、比较口径和排除规则透明；不存在把不可访问来源或模型记忆写成事实的项目。
- 每个关键结论可回链证据矩阵；事实、管理层陈述与分析推断分开标注；区分 TAM 与现实可及市场，数据时点已标注。
- 公司对比表同口径；图表轴、期间和单位与底稿一致。
- 产物结构有效，关键数字一致；未完整渲染时披露 `FULL_RENDER_UNVERIFIED`。
