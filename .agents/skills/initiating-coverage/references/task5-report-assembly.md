# Task 5: Report Assembly

只在组装 initiating coverage 最终报告时读取。

## 结构

按用户模板和受众组织，通常包含：investment thesis、valuation、catalysts、risks、business/industry、competitive position、financials、scenarios 和 sources。篇幅由问题和证据决定，不使用固定页数或图表数量强行填充。

用户没有报告模板时，读取 [`report-template.md`](report-template.md) 作为可覆盖的结构骨架。

## 组装规则

- Headline 与 executive summary 先给可证伪结论，再给证据和限制。
- 报告中的 actuals、forecasts、valuation 和 charts 与最终模型一致。
- 事实、管理层陈述、`USER_PROVIDED` 输入、`MODEL_DERIVED` 情景和分析推断明确区分。
- 每个关键数字有链接或可定位 source；搜索摘要不是最终引用。
- 风险与 bull case 使用同等证据标准；不隐去 material gap。
- Rating/target price 若用户需要，必须显示估值日期、方法、输入状态和 downside/upside 计算。

交付前检查目录/标题、页码、表格和图表引用、超链接、跨页数字、拼写、overflow 与 source section。按统一 artifact 契约报告结构、公式和完整渲染限制。
