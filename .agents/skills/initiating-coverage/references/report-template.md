# Initiating Coverage Report Skeleton

只在用户没有报告模板时读取；结构可按受众和证据调整。

## Header

- Company / ticker / exchange
- Report date / valuation date / currency
- Rating or stance（仅当用户要求且有方法支持）
- Target price / current reference price / upside-downside（输入完整时）
- Primary source and limitation notice

## Executive view

- One-sentence falsifiable thesis
- Key evidence
- Valuation method and result range
- Catalysts
- Risks / invalidation conditions

## Body modules

1. Business model and revenue drivers
2. Industry/value chain and competitive position
3. Historical financials and KPI analysis
4. Forecast drivers and scenarios
5. Valuation and sensitivities
6. Catalysts, risks and monitoring plan
7. Sources, assumptions and limitations

每个 module 只加入支持结论的表格/图表。Actual、guidance、`USER_PROVIDED`、`MODEL_DERIVED` 和 `SOURCE_UNAVAILABLE` 状态必须清楚；页数、图表数和版式密度不是完成标准。
