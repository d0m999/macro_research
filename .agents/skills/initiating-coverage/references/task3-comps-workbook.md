# Comps Workbook Layout

仅在用户没有现成模板时读取。

建议最小结构：

1. `Summary`：估值日期、peer set、关键统计、目标公司隐含估值和主要限制。
2. `Comps`：公司、经营数据、capitalization、EV adjustments、multiples 和统计行。
3. `Target`：目标公司指标、selected multiple、EV-to-equity bridge 和 per-share output。
4. `Sources`：每个 hardcode 的 source record、期间、单位和状态。

格式只服务可读性：区分 inputs、formulas、cross-sheet links 和 key outputs；显示单位、币种、Actual/Estimate；冻结 labels/header。模板或用户样式优先。
