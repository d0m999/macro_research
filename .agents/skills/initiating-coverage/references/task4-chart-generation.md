# Task 4: Chart Generation

只在 initiating coverage 需要图表时读取。

按论点选择最小充分图表，可覆盖价格表现、收入/利润率、segment/geography、KPI、cash flow、capital structure、peer positioning 或 valuation。数据不完整的图表省略并记录原因，不用模型记忆补线。

每张图必须：

- 标题表达 insight，而不是只写指标名；
- 显示期间、单位、币种、Actual/Estimate 和必要的口径说明；
- 引用 source manifest 或 model range；
- 使用不误导的 axis、排序和 scale；
- 与报告/模型相同数字和舍入口径；
- 对 `MODEL_DERIVED` series 明确标记情景属性。

完成时逐张核对 source、数据范围、标签、可读性和论点相关性。图表数量不是完成标准。
