# Strip Profile Layouts

只在用户没有模板或需要选择模块布局时读取。

## Single-page profile

用一个主 takeaway 组织以下最小充分模块：identity/header、business overview、key facts/KPIs、financial/valuation snapshot、ownership/transactions（如有）、sources。数据缺失时删除模块或标明缺口，不用空框制造完整感。

## Multi-page profile

按证据拆分，不固定页数：

- Overview and positioning
- Products/customers/geography
- Financials and KPIs
- Capitalization, ownership, transactions or valuation

每页保持同一估值日期、币种、单位和 Actual/Estimate 口径。布局尺寸是可覆盖的视觉默认，不是金融事实。

## QC

检查 headline 与数据一致、图表来源、footnote 可读、表格小数位、logo safe area、overflow、overlap、cropping 和 slide master 继承。
