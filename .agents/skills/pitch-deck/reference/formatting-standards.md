# Pitch Deck Formatting

只在填充文本、表格、图表或检查版式时读取。

- 保留 template master、layouts、theme、page size、fonts、colors、footer 和 logo safe area。
- 更新已有 placeholder/shape，避免重建造成 master 或 animation 丢失。
- 标题表达单页结论；正文、表格和图表保持清晰层级。
- 数字右对齐，小数位、currency、percent、multiple 和 negative format 跨页一致。
- 来源区包含 publisher/document、date、page/section 或链接；字体仍须可读。
- 检查 text overflow、shape overlap、cropping、off-slide elements、字体替换、alignment 和 z-order。

尺寸和间距服从模板。没有现成规则时可以采用可读的排版默认，但它们不是金融事实，可由用户覆盖。
