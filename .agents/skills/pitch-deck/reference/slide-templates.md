# Pitch Deck Slide Mapping

只读取当前任务涉及的 slide 类型。

| Slide type | 常见输入 | 关键检查 |
|---|---|---|
| Executive summary | 关键结论、交易/公司事实、next steps | 结论与后页证据一致 |
| Company overview | 业务、产品、客户、地域、KPI | 日期、口径、公开/用户来源 |
| Market | 市场定义、规模、增长、驱动 | Universe 一致，不混用来源口径 |
| Financial profile | 历史/预测财务、margin、cash flow | Actual/Estimate、单位和模型一致 |
| Trading comps | peers、EV bridge、metrics、multiples | 估值日期、NM、peer rationale |
| Precedents | 官方交易事实、metric period、multiples | announce date、status、口径 |
| Transaction | price、sources/uses、financing、timeline | 仅用公开或 `USER_PROVIDED` terms |
| Valuation summary | 方法输出、ranges、bridge | 区间/权重有来源或 `MODEL_DERIVED` 理由 |

只填充模板中存在或用户要求的 slides；不要把这张表当作固定 deck 目录。
