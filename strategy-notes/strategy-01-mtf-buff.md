# 策略 1：多时间框架 Buff 共振（MTF Buff Confluence）

> 状态：草稿 v0.5（§4.4 已重构为 **Setup A / Setup B 双牌型**，分流框架与三项裁决**已确认（2026-07-13）**；§4.6 OI 确认层**不对称接入已确认（2026-07-13）**；**§4.3 计分公式挂起待议**；RVOL 阈值、衍生品盘面例行为待议项；参数待回测校准）
> 记录日期：2026-07-12
> 品种：crypto
> 类型：**时序策略**（time-series / 单标的方向性择时），非截面策略

## 1. 策略本质

这是一个**时序策略**：只对单一标的的时间序列做多空方向判断，不做横截面排序、不做配对套利。收益来源是价格自身的趋势延续与均值回复，而非标的之间的相对强弱。

核心思想一句话：**在多个时间框架上，用多个独立指标同时确认同一方向，每一个确认算一个 buff；buff 叠加到足够厚度才下场。**

单指标 = 噪声源；多指标 × 多周期共振 = 信号。这本质上是在做**信噪比的乘性放大**——每个 buff 都是一次独立（或准独立）的证据采样，独立证据越多，方向判断的后验概率越高。

## 2. 指标体系（三件套）

全部来自 `PineScript/_L∞p/`，是 TradingView 上的研究原型，后续需转译为 Python 供回测。

### 2.1 结构层：`L∞p | ATR-zigzag.pine` — 价格结构（HH/HL vs LH/LL）

**作用**：客观化"趋势"的定义，判断价格处于上升结构还是下降结构。

**参数（当前）**：

| 参数 | 值 | 说明 |
|---|---|---|
| `atrLength` | 10 | ATR 周期 |
| `pivotLength` | 3 | 枢轴点检测窗口（必须奇数，left=right=1） |
| `atrMultiplier` | 2.0 | 新枢轴点距上一枢轴点必须 ≥ 2×ATR 才成立 |
| `maxLines` | 100 | 保留最近 N 条 ZigZag |

**逻辑**：ATR 乘数是一个**自适应噪声门槛**——只有幅度超过 2 倍当期波动率的摆动才被认定为有效枢轴。这使得 ZigZag 在高波动期自动变钝、低波动期自动变灵敏，避免了固定百分比阈值在不同波动 regime 下失效的经典问题。

**结构判定规则**（由枢轴序列推导）：

- **上升结构（看多 buff）**：最近的高点 > 上一个高点（Higher High）**且** 最近的低点 > 上一个低点（Higher Low）
- **下降结构（看空 buff）**：最近的高点 < 上一个高点（Lower High）**且** 最近的低点 < 上一个低点（Lower Low）
- **结构破坏（警告 / 反向预备）**：HH + LL 或 LH + HL 混合，视为结构转换中，**不给 buff**

> ⚠️ **重绘风险（必须记入回测约束）**：`pivotLength=3` 意味着枢轴点需要右侧 1 根 K 线确认，即枢轴在**滞后 1 根 K 线**后才成立；且 `updatePivot()` 会在同向出现更极端值时**回头修改已画出的枢轴**。在实盘/回测中，只能使用**已确认且不再更新**的枢轴，否则会引入前视偏差（look-ahead bias）。这是本策略工程化时的第一号陷阱。

### 2.2 趋势与动态支撑阻力层：`L∞p | MA.pine` — 6 条 EMA

**作用**：(a) 趋势方向与强度；(b) **动态**支撑/阻力区域。

**参数**：EMA 21 / 55 / 100 / 200 / 300 / 400（源均为 `close`）

**用法**：

- **趋势 buff（排列）**：
  - 多头排列：`EMA21 > EMA55 > EMA100 > EMA200`，且价格在 EMA21 上方
  - 空头排列：反向
  - 缠绕/交织：**不给 buff**（这是最容易亏钱的状态，宁可空仓）
- **动态 S/R buff（回踩确认）**：价格回撤触及某条 EMA 后**收线站回其上**（做多）/**收线压回其下**（做空）。EMA 周期越长，该支撑/阻力的分量越重（EMA200/300/400 > EMA21/55）。
- **多条 EMA 密集重叠处 = 高强度 S/R 带**，突破/受阻的信息含量显著高于单条。

### 2.3 过滤层：`L∞p | RSI.pine` — 自适应去趋势 RSI（detrender RSI）

**作用**：**过滤掉非超买超卖区域，不在中性区交易。**这是本策略的"闸门"——RSI 在中性区时，方向性赔率接近随机，不下场。

**关键机制**：这不是普通 RSI。它先用**希尔伯特变换**估计市场主导周期（`market_frequency = median(360/phaseAngle, 100)`），再取 `period = market_frequency / 2` 作为 RSI 的自适应长度，最后用 `HMA(21)` 平滑。也就是说，**RSI 的回看长度会随市场节奏自动伸缩**，而不是死板的 14。这解决了固定周期 RSI 在不同周期结构下超买超卖阈值漂移的问题。

**参数**：

| 参数 | 值 | 说明 |
|---|---|---|
| `smoothlength` | 21 | HMA 平滑长度 |
| `medianLength` | 100 | 主导周期中位数检测长度 |
| `lbL` / `lbR` | 12 / 1 | 背离检测枢轴窗口 |
| 超买 / 超卖 | 80 / 20 | 阈值带 |
| Squeeze | BB(20, 2.0) vs KC(20, 1.2, EMA) | 布林带被肯特纳通道包住 = 挤压 |

**可产出的信号（各自算独立 buff）**：

1. **区域 buff**：`rsi_v < 20`（超卖 → 多头）/ `rsi_v > 80`（超买 → 空头）
2. **转向 buff（强信号 ▲/▼）**：从 <20 区域向上拐头（`▲` 白三角）/ 从 >80 区域向下拐头（`▼` 蓝倒三角）。**这比单纯身处极值区更强**——极值可以一直更极值，拐头才是动能反转的确认。
3. **背离 buff**：常规看涨背离（价格创新低、RSI 未创新低）/ 常规看跌背离（价格创新高、RSI 未创新高）。**背离与 ZigZag 结构天然互补**：结构说"还在跌"，背离说"跌不动了"。
4. **挤压 buff（Squeeze）**：`isSqueeze` 期间波动率被压缩（背景高亮），`squeezeFired` = 挤压释放。挤压释放本身**不带方向**，它是一个**波动率择时器**——用于决定"何时打"，方向仍由结构 + EMA + RSI 决定。挤压中：观望或轻仓；挤压释放 + 方向 buff 齐备：这是最优的下场时点。

## 3. 静态支撑阻力（人工标注层）

除指标外，**用 K 线肉眼标注的水平价格区域**（前高/前低密集成交区、多次触及被拒绝的价位）是独立的一层证据。

**实例（2026-07-12，ETHUSDT.P 日线）**：价格在 **~1814.78** 区域**三次触及被压回**（见 5 月末、6 月中、7 月初三个 ZigZag 高点均终止于该水平带），构成明确的**日线级别静态阻力**。当前价 1805，正贴在该阻力下沿。

**规则**：

- 价格贴近大级别静态阻力下方 → **做多的否决项（veto）**，即使其它 buff 齐备也不追多；同时是做空信号的**加权 buff**。
- 反之，贴近大级别静态支撑上方 → 做空的否决项 / 做多的加权 buff。
- 静态位一旦被**放量实体突破并回踩确认**，则支撑阻力**角色互换**（阻力转支撑），原 veto 解除。

> 这一层目前是人工判断。工程化时的方案：用 ATR-ZigZag 的枢轴点做**价格聚类**（把多次落在同一价带的枢轴聚成 S/R 带，触及次数 = 强度权重），即可把"肉眼"变成可回测的代码。

## 4. 多时间框架 Buff 计分系统（策略核心）

### 4.1 监控的时间框架与权重

**时间级别越大，置信度越高。**大级别决定方向与仓位上限，小级别只用于择时入场。

| 周期 | 权重 | 角色 |
|---|---|---|
| **1W（周线）** | 4 | 战略方向，最高否决权 |
| **1D（日线）** | 3 | 主战场方向 |
| **4H** | 2 | 中期确认 |
| **1H** | 1 | 入场结构 |
| **15m** | 0（不计分） | **仅用于择时/精确入场点**，不参与方向投票 |

> 权重为初稿，**待回测校准**。校准方法：对每个 (周期 × 指标) 组合单独统计其信号后的前瞻收益 IC（信息系数），用 IC 的相对大小反推权重，而非拍脑袋。

### 4.2 Buff 的定义

**一个指标在一个时间框架上给出一次方向性确认 = 1 个 buff。**

单个时间框架内可产生的 buff（各维度独立，同维度不重复计数）：

| # | 维度 | 多头 buff 条件 | 空头 buff 条件 |
|---|---|---|---|
| B1 | **结构**（ZigZag） | HH + HL | LH + LL |
| B2 | **趋势**（EMA 排列） | EMA 多头排列 + 价格在 EMA21 上 | EMA 空头排列 + 价格在 EMA21 下 |
| B3 | **动态 S/R**（EMA 回踩） | 回踩 EMA 后收线站回其上 | 反弹至 EMA 后收线压回其下 |
| B4 | **RSI 区域** | `rsi_v < 20` | `rsi_v > 80` |
| B5 | **RSI 转向** | 从超卖区上拐（▲） | 从超买区下拐（▼） |
| B6 | **RSI 背离** | 常规看涨背离 | 常规看跌背离 |
| B7 | **波动率**（Squeeze） | `squeezeFired` 且方向 buff 已齐（**择时用**，方向中性） | 同左 |
| B8 | **静态 S/R**（人工） | 位于大级别静态支撑上方 | 位于大级别静态阻力下方 |

### 4.3 计分公式（AI 提案，未约定）

> ⚠️ **来源标注**：本节公式由 AI 起草，**非本人约定**。线性加权求和只是最简单的基线形态，且隐含"各证据近似独立"的假设——相关维度同时计分会被隐性重复加权。计分方式本身（线性求和 / 按证据族计分 / 族内设上限 / 非线性）均属待定项，回测阶段允许整体推翻。

```
方向得分 = Σ (周期权重 × 该周期内该方向的 buff 数量)

净得分 = 多头得分 − 空头得分
```

### 4.4 入场牌型（v0.4 重构：Setup A / Setup B 分流）

> **来源标注**：分流框架与三项裁决**已经本人确认（2026-07-13）**——① Setup B 豁免大级别方向锁；② Setup B 初始风险降档（r = 0.5%–1%）；③ 即日起每笔交易记账标注 setup 类型。**牌内具体条款仍为 AI 起草的候选规则**，逐条以盘感验证 + 回测证据为准。数字化门槛（是否保留"净得分 ≥ T"）挂起，待 §4.3 计分结构定案后再议。

开仓 = 命中下面**任意一张牌的全部条件**。两张牌捕捉签名相反的两类机会：**A 供月频率，B 供右尾**（对应 §7 条款 6 目标函数的两个因子），分别评估、分别记账、互不混用。

#### 牌 A · 顺势回踩（频率引擎）

1. **方向锁（A 专属）**：1D 或 1W 的趋势族（B1 结构 / B2 排列）与交易方向一致——A 只做趋势延续
2. **回踩证据**：价格回撤至动态 EMA（B3）或静态支撑带（B8 顺位），收线确认
3. **动量复位**：入场周期（1H/4H）动量族回撤后拐头（B5）或自极值区回归
4. **veto**：大级别静态 S/R 反向贴脸（§3）；EMA 缠绕期不做
5. **择时加分**：Squeeze 释放（B7）、15m 入场结构

预期画像：胜率偏高、R 中等（2–4R）、贡献月频率。初始 r 按 §6.4 档位（1%–2%）。

#### 牌 B · 极值反转（右尾引擎）

1. **方向资格（已确认：豁免方向锁）**：允许逆 1D/1W 趋势族开仓，但必须**同时**具备：
   - 高周期（1D/1W）动量族极值（B4）
   - **背离（B6）——衰竭的硬证据。无背离的裸极值不做**（"极值可以一直更极值"）
2. **结构衰竭**：ZigZag 摆动幅度收缩 / 失败摆动（动能衰减的结构证据）
3. **择时**：Squeeze 释放（B7）或入场周期动量拐头（B5）
4. **veto**：大级别静态 S/R 反向贴脸（§3）
5. **OI 确认层（已确认：不对称接入，详见 §4.6）**：
   - **反签名 veto（硬规则）**：做多遇"跌 + OI↑"型下跌（新空进场推动）→ 直接否决；做空遇"涨 + OI↑"型上涨 → 同理否决
   - **正签名加分（软规则）**：做多见"天量 + OI 骤降"（多头清算投降）、做空见"涨 + OI↓"（空头回补衰竭）→ 加分项，**不是必要条件**

预期画像：胜率低（25%–35%）、右尾肥（+8R 级）、贡献偏度。**初始 r 降档至 0.5%–1%（已确认），不适用 §6.4 加档表**；出场端禁止提前剪尾（§6.2/§6.3）。

#### 记账规则（已确认，即日起执行）

每笔交易在手动账本中标注 `setup ∈ {A, B}`，胜率 / 每笔期望 / 频率 / 回撤**分开统计**。两张牌是两个子策略：合并统计会互相污染——A 的高胜率掩盖 B 的常态低胜率，B 的肥尾扭曲 A 的每笔期望。

> 旧版条款 4（维度多样性）由牌型构造天然满足——每张牌都强制跨证据族取证；其一般化形式（按证据族计分）挂起待 §4.3。

### 4.5 实例分析：2026-07-12 ETHUSDT.P（当前为"不下场"）

多周期 RSI 快照：

| 周期 | RSI | 判读 |
|---|---|---|
| 1W | 22.71 | 接近超卖 → 潜在**多头** buff（权重 4） |
| 1D | 77.80 | 接近超买 → 潜在**空头** buff（权重 3） |
| 4H | 57.67 | **中性区 → 无 buff** |
| 1H | 50.57 | **中性区 → 无 buff** |
| 15m | 73.55 | 不计分 |

**结论：观望，不开仓。**（v0.4 起改用双牌评估路径）

- **牌 B（做多反转）不成立**：1W 22.71 接近但未入超卖（B4 未成立）、**无背离（B6 缺失，硬条件）**、无结构衰竭证据、Squeeze 未释放；且价格 1805 紧贴 1814.78 静态阻力下方——**veto 生效**。裸极值 + 阻力贴脸，正是 B 牌明令不做的形态。
- **牌 A（做多）不合格**：1D 趋势族向下（EMA 空头排列，价格在 EMA100/200/300/400 之下），方向锁不通过。
- **牌 A（做空）时点未到**：方向锁通过（顺 1D 空头趋势），1D RSI 77.80 接近超买（反弹到位的雏形）；但入场周期动量族无信号（4H 57.67 / 1H 50.57 全在中性区、无拐头）——回踩证据与动量复位均未出现。另 1W 接近超卖警示大级别反弹风险，即使后续成立也应压缩预期持仓周期与 R。
- （旧版单门槛路径结论相同，但理由是"净得分不足 + 闸门否决"——路径不同，遇到证据充足的反转单时结局会不同，这正是分流的意义。）

这正是牌型系统的价值所在：**它把"看起来周线要反转了、想抄底"的冲动，拆解成一张牌的明确不合格清单。**不亏钱的交易，和赚钱的交易一样重要。

### 4.6 OI 确认层（已确认：不对称接入，2026-07-13）

**接入总原则**：OI 是**确认/否决调制器**，不进加分维度。它的含义随价格上下文翻转——同样的 ΔOI 在不同价格方向下含义相反，含义条件依赖的变量不能当固定符号的加分项，只能作为牌型内的条件项。

**价格 × ΔOI 状态矩阵**（读数以币本位 OI 为准）：

| | OI ↑ | OI ↓ |
|---|---|---|
| **价涨** | 新多进场，趋势有燃料（牌 A 顺风确认） | 空头回补，无新赞助（牌 A 警惕衰竭；**牌 B 做空的正签名**） |
| **价跌** | **新空进场，下跌有推手（牌 B 做多 veto）** | **多头清算投降（牌 B 做多的正签名）** |

**不对称规则（已确认）**：

- **反签名 veto = 硬规则**：B 多遇"跌 + OI↑"、B 空遇"涨 + OI↑"，直接否决。这是"接刀死法"中最机械可辨的一种——对手方是新进场的趋势资金，不是正在离场的旧仓。
- **正签名 = 软加分**：B 多的"天量 + OI 骤降"（清算投降）、B 空的"涨 + OI↓"（回补衰竭）只加分、不设必要。设为必要会在 OI 读数模糊的场次砍掉 B 类频率，损失未量化前不上硬约束。"天量"的 RVOL 量化阈值待议，暂以人工判读。
- **升级复核**：B 类记账增加一列「正签名 有/无」，累计约三个月或 ≥20 笔后对比两组的 R 分布——若"有签名"组显著占优，再议升级为必要条件。
- **分向验证**：加密市场底部的多头清算瀑布通常比顶部的空头回补更剧烈、签名更干净——B 多正签名的预期可靠度高于 B 空，记账时分方向统计。

**数据与工程注记**：

- 读数必须用**币本位 OI**。USD 计价会把价格机械乘进去（2026-07-13 对账验证：ETH 聚合 OI 的 USD 口径半年 −38%，币本位实际 +14%，结论相反）。

## 5. 交易流程（Checklist）

```
1. 【定牌】这是哪类机会？顺势回踩 → 牌 A；极值反转 → 牌 B   （§4.4）
2. 【否决】标注大级别静态 S/R → 是否存在反向 veto？有 → 直接放弃（两张牌通用）
3. 【验牌】A：方向锁（1D/1W 趋势族同向）→ 回踩至支撑收线确认 → 入场周期动量复位
         B：高周期动量极值 + 背离（缺一不可）→ 结构衰竭证据 → OI 反签名检查（跌+OI↑ 禁多 / 涨+OI↑ 禁空，§4.6）
4. 【择时】等 Squeeze 释放 / 15m 出现入场结构 → 准备下单
5. 【止损】★先定止损★：结构位（被多次测试的 MA / K 线支撑）之外 − 0.5×ATR   （§6.1）
6. 【仓位】以损定仓：名义仓位 = (权益 × r) / 止损距离%；r：A 类 1%–2%（档位挂起），B 类 0.5%–1%（已确认）  （§6.4）
7. 【持仓】棘轮上推止损（每破一个阻力 → 阻力转支撑 − ATR 垫）；4H/D 超买 → 减初始仓 5%  （§6.2 / §6.3）
8. 【离场】止损被触发 / 大级别 buff 消退 / 结构破坏（LH+LL）  （§6.6）
9. 【记账】标注 setup ∈ {A, B} + 结果（按 R 计）→ 两套统计分开看   （§4.4 记账规则）
```

## 6. 风险控制

风控三支柱：**结构化止损**（定亏损）→ **以损定仓**（定仓位）→ **棘轮式移动止损 + 分批主动减仓**（定盈利）。

注意顺序：**止损位必须先于仓位确定**——因为仓位是由止损距离倒推出来的，而不是先拍一个仓位再想止损放哪。这是整套风控的逻辑起点。

### 6.1 止损：结构位 + ATR 安全垫

**止损永远放在结构位之外，而不是放在一个固定的百分比上。**市场不知道你的成本价，但它认得支撑阻力。

**多单**——止损放在下方最近的**有效支撑**之下：

- 候选支撑（取价格下方最近的 / 被反复测试过的）：
  1. **被多次测试的 MA**（EMA21/55/100/200/300/400 中的一条；被测试次数越多、周期越长，分量越重）
  2. **K 线上被多次测试的静态支撑位**（前低密集带 / ZigZag 枢轴聚类）
- **止损价 = 支撑位 − N × ATR**，其中 N 为安全垫系数（**初稿 N = 0.5，待校准**）

**空单**——反之：止损 = 上方最近的有效阻力 + N × ATR

> **为什么用 ATR 而不是固定百分比做安全垫**：ATR 让安全垫随波动率自适应。高波动期自动放宽（避免被正常回踩扫损），低波动期自动收紧（避免让出过多利润）。固定百分比在波动率 regime 切换时必然失效——要么频繁被扫，要么止损过远拖垮盈亏比。

### 6.2 主动止盈：等额分批减仓

- **触发**：**4H 或 1D** 的 RSI 进入超买（多单）/ 超卖（空单）
- **每次减仓量**：**初始仓位数量的 5%**（等额分批 → 理论上最多 20 次可完全出清）
- **单向**：只减不加，不做金字塔加仓

> ⚠️ **实现细节待定（必须回测确认）**：触发条件用「**身处**超买区（`rsi_v > 80`）」还是「**从超买区拐头**（`▼` 信号，`crossunder` from >80）」？
> - 用「身处超买区」：会**每根 K 线重复触发**，需要额外去重逻辑；且在强趋势中 RSI 可以长期钝化在 80 以上，会导致过早、过度削减仓位——**在最该让利润奔跑的行情里反而砍得最狠**。
> - **推荐用 `▼` 拐头信号**：天然自带去重（一次超买事件只触发一次），且是动能反转的确认而非仅仅"过热"。
>
> 这个选择对最终收益的影响可能比任何一个 buff 权重都大，必须 A/B 回测。

### 6.3 被动止盈：阻力转支撑的棘轮式移动止损（核心利润引擎）

浮盈期间**不断上推止损**（多单）：

- 每当价格**收线有效突破**一个阻力位（MA 或 K 线静态阻力）：
  1. 该阻力位**角色转换为新支撑**
  2. **止损上移至：新支撑 − N × ATR**（与 §6.1 同一套安全垫逻辑）
- **棘轮原则（ratchet）**：止损**只上移，永不下移**。空单反之，只下移不上移。

> **这是整套策略的利润引擎，也决定了它的收益分布形态。**主动止盈每次只削 5%（几乎不影响主仓），大头利润全靠移动止损被动兑现——本质是一台**趋势跟随收割机**。
>
> **必然的统计后果（回测时不要误判为 bug）**：收益分布是**正偏度**的——「小亏多次 + 大赚少次」。**胜率会偏低（可能 35–45%），这是设计的一部分，不是缺陷。**评价这个策略必须看**期望值、盈亏比（payoff ratio）和最大回撤**，绝不能看胜率。任何以提高胜率为目标的"优化"，几乎都会破坏这台引擎——那是在剪掉正偏度的右尾。

**正偏度分布图解**——把每笔交易的盈亏（按 R 计，1R = 单笔风险预算）画成直方图，这个策略的账本应该长这样：

```
笔数
 │      ██
 │      ████
 │      ██████
 │    ████████
 │    ██████████▁▁
 │    ████████████████▁▁▁▁      ▁▁        ▁
 └────┴────┴────┴────┴────┴────┴────┴────┴────→ 单笔盈亏
     -1R    0   +1R  +2R  +3R  +4R ...  +8R  +12R
  ← 左尾                              右尾 →
```

三个区域，对应三套机制：

| 区域 | 含义 | 负责的机制 |
|---|---|---|
| **左尾**（极端大亏） | 不允许存在 | 结构化止损（§6.1）把单笔亏损焊死在约 −1R，杜绝 −5R 灾难单 |
| **中间**（小亏/小赚/平） | 数量最多、贡献近零 | 趴着不动的废单可引入时间止损清场（候选优化项） |
| **右尾**（少数大赚） | **全部净利润的来源** | 棘轮移动止损（本节）放养——趋势跑多远就跟多远 |

**典型账本（示意）**：100 笔 = 60 笔小亏（−60R）+ 30 笔小赚/平（+15R）+ **10 笔大赚（+70R）** → 净利 +25R。右尾 10 笔贡献了远超 100% 的净利润——把它们拿掉，这是个亏钱系统。

**「剪右尾」的具体形态**（共同点：都让胜率变好看，但期望值下降）：

- 固定止盈目标：到 +2R 全平 → +8R 的单从账本上永远消失
- 过早保本止损：趋势中途回踩成本价，把本来 +6R 的单变成 0
- 「身处超买就减仓」：RSI 在强趋势中可钝化在 80 上方数十根 K 线，会在最肥的一段把仓位削光（即 §6.2 悬案中不推荐的那个选项）

一句话：**左尾用止损焊死，右尾用移动止损放养，中间的废单清场——这个分布形状就是策略本身。**

### 6.4 仓位管理：以损定仓（Risk-Based Position Sizing）

**先定止损，再由止损距离倒推仓位，使每一单的最大亏损恒定。**

```
风险金额 R      = 账户权益 × 风险比例 r        （r ∈ [1%, 2%]）
止损距离 d%     = |开仓价 − 止损价| / 开仓价
名义仓位（U）   = R / d%
下单数量        = R / |开仓价 − 止损价|
```

**验算（原始示例）**：本金 10000，r = 1% → R = 100 U；开仓价 100，止损 95 → d% = 5%
→ 名义仓位 = 100 / 5% = **2000 U** = 20 个单位
→ 止损触发时亏损 = 20 × (100 − 95) = **100 U = 本金的 1%** ✓

**风险比例 r 与证据厚度挂钩**（仅适用 **Setup A**；档位划分挂起，待 §4.3 计分结构定案后重定标）：

| 净得分（§4.3，挂起） | 风险比例 r |
|---|---|
| T ≤ 得分 < T+4 | 1.0% |
| T+4 ≤ 得分 < T+8 | 1.5% |
| 得分 ≥ T+8 | 2.0% |

**Setup B 一律降档（已确认，2026-07-13）：r ∈ [0.5%, 1.0%]，不适用上表。**低胜率牌型用小初始敞口换肥尾——B 类的仓位逻辑是"买一张便宜的彩票"，不是"重仓一次确定性"。

> **账户权益的口径**：建议用**已实现权益**（不含未平仓浮盈）计算 R。若用含浮盈的权益，会在连胜时自动放大仓位——这是**顺周期加杠杆**，是账户在一次反转中被打穿的经典路径。让仓位随浮盈膨胀，等于把趋势末端的风险敞口开到最大。

### 6.5 已知风险（决策：不设名义仓位上限）

**已明确选择纯以损定仓、不设名义仓位/杠杆上限。**这是有意识的选择，但必须知道敞口在哪里：

**止损越近 → 名义仓位越大 → 所需杠杆越高**（本金 10000，r = 1%）：

| 止损距离 d% | 名义仓位 | 相当于本金 |
|---|---|---|
| 5% | 2,000 U | 0.2× |
| 2% | 5,000 U | 0.5× |
| 1% | 10,000 U | 1.0× |
| 0.5% | 20,000 U | **2.0×** |
| 0.25% | 40,000 U | **4.0×**（r=2% 时为 8.0×） |

**三个必须计入的现实摩擦**（否则回测的 1% 风险是假的）：

1. **爆仓可能先于止损**：逐仓保证金下，若该仓位分配的保证金过少，**强平价可能落在止损价之内**——止损还没触发就已经被强平。**缓解（不改变仓位公式）**：给该仓位分配足够保证金 / 降低杠杆倍数，确保**强平价显著远于止损价**。这只改变保证金占用，不改变名义仓位，因此与以损定仓不冲突。
2. **手续费 + 资金费率侵蚀 R**：实际亏损 = 止损亏损 + 双边手续费 + 持仓期资金费。名义仓位越大，手续费绝对值越大——而以损定仓在近止损时恰恰给出巨大名义仓位。回测必须计入，否则名义上的 1% 风险实际可能是 1.1%–1.3%。
3. **滑点与跳空**：止损单不保证成交价。插针 / 跳空时实际成交可能远劣于止损价，**单笔亏损可超过 R**。杠杆越高，这个尾部越致命。

**天然缓解**：本策略的止损位由 MA / 结构支撑决定，通常不会紧贴入场价，因此 d% 极小的情况本就不多。若某次信号算出 d% 异常小（如 < 1%），意味着入场点极度贴近支撑——**这本身是优质入场点**，但**必须人工确认保证金充足**，否则就是在最好的入场点上用最高的杠杆承担爆仓风险。

### 6.6 失效离场（未触止损也主动离场）

- **大级别 buff 消失/反转**：1D 或 1W 的方向 buff 归零或转向 → 主动减仓或离场
- **结构破坏**：多单持仓期间 ZigZag 出现 LH + LL（空单出现 HH + HL）→ 结构失效，离场
- 逻辑：**进场靠 buff 叠加，离场也该看 buff 消退。**支撑你开单的证据没了，就不该还在场上——不要等价格来告诉你，那时已经付出了完整的止损。

## 7. 工程化落地路径（后续）

1. **Pine → Python 转译**：三个指标转为 `components/indicators/` 下的模块（ZigZag 已有雏形 `atr_zigzag.py`，自适应 RSI 已有 `adaptive_resonance.py`）。
2. **消除前视偏差**：
   - ZigZag 枢轴必须用**已确认**的（滞后 `rightBars` 根），禁止使用会重绘的最新枢轴。
   - MTF 数据必须用 **已收线** 的高周期 K 线（freqtrade `merge_informative_pair` 默认行为，需确认 `ffill` 与移位正确）。
3. **Buff 计分向量化**：每个 (周期, 维度) 输出一列布尔信号 → 加权求和为 `buff_score` 列。
4. **风控映射到 freqtrade 接口**：

   | 规则 | freqtrade 钩子 | 注意 |
   |---|---|---|
   | 以损定仓（§6.4） | `custom_stake_amount()` | 需在此处先算出止损价才能倒推 stake；stake 是**保证金**不是名义仓位，需除以杠杆换算 |
   | 结构止损 + 棘轮移动止损（§6.1/§6.3） | `custom_stoploss()` | 返回值是**相对开仓价的负比例**；棘轮天然满足（freqtrade 只接受更紧的止损） |
   | 分批主动止盈 5%（§6.2） | `adjust_trade_position()` | **必须设 `position_adjustment_enable = True`**，返回负值代表减仓 |
   | 失效离场（§6.6） | `custom_exit()` | |
   | 杠杆 | `leverage()` | 保证强平价远于止损价（§6.5） |

5. **参数校准**：权重、阈值 T、安全垫 N 不拍脑袋，用 IC / 分层回测校准。**警惕过拟合**——本策略自由度很高（5 周期 × 8 维度 + 权重 + T + N + r），参数空间足以拟合任何历史曲线。样本外（walk-forward）验证必须严格，且**回测必须计入手续费与资金费率**（见 §6.5），否则以损定仓的风险预算是假的。
6. **评价指标（目标函数）**：优化目标是**单位时间期望值 = 每笔期望 × 月频率**，约束条件是**最大回撤**。辅助观察盈亏比与收益偏度，**不看胜率**（原因见 §6.3）。
   - 单独盯"每笔期望"会走向过度过滤：门槛越加越高，每笔越来越漂亮，但月频率掉到忽略不计——账户层面等于没有策略。
   - 单独盯"频率"会走向信号稀释：什么都下场，每笔期望被摊薄至手续费之下。
   - 两者相乘才是账户真正的赚钱速度；最大回撤作为约束（而非目标）防止用杠杆/敞口虚增乘积。
7. **回测 → Hyperopt → Dry-run → 实盘**。
