# 加密永续多因子登记表（crypto-perp）

> 标的：BTCUSDT USDⓈ-M 永续（`BINANCE:BTCUSDT.P`），单交易所、非聚合、UTC、已收盘柱。
> 数据落地：`data/raw/binance-futures/`，采集脚本 `tools/factors/crypto-perp/collect.py`。
> 建立日期：2026-09-20。本表是**先登记后跑**的冻结清单：因子定义与门槛在此写定，跑完不再回头改。

## 0. 边界

- 本线是**离线统计分析层**，不是交易执行层。按 `CLAUDE.md`，不引入 FreqTrade、下单、账户、Docker 或交易数据库。
- 所有因子只使用公开只读行情。数据来源、口径、窗口必须逐条标注，不得把不同口径混写。
- 本表的因子方向假设是**待检验假设**，不是结论。跑完必须按 §5 报「通过 / 拒绝 / 样本不足」。

## 3. 标签（预测目标）

```
fwd_n = close.shift(-n) / close - 1      n ∈ {1, 3, 5, 10}
```

⚠️ 重叠样本：`fwd_5` 的相邻观测共享 4 天收益，独立样本数约为 `n/5`。所有显著性判定必须按**有效样本量** `n_eff = n / n_horizon` 计算，或做抽样降重叠。不处理会把 t 值虚增约 √n 倍。

## 4. 检验口径

1. **指标**：Spearman 秩相关 IC（主）；分位 5 组的组均收益单调性（辅）。两者必须同向，否则判失败。
2. **门槛**：零假设下 IC 标准误 `SE ≈ 1/√(n_eff - 1)`，临界 IC = `t_crit × SE`。

   | 样本量（有效） | 单因子 t=2 门槛 \|IC\| | 20 因子 Bonferroni 门槛 \|IC\| |
   |---:|---:|---:|
   | 2570（A 层，n=1） | 0.039 | 0.060 |
   | 514（A 层，n=5） | 0.088 | 0.133 |
   | 299（既有 CSV） | 0.116 | 0.175 |
   | 31（B/C 层） | **0.365** | **0.551** |

   ⇒ **B 层与 C4–C8 当前在统计上不可检验**。真实因子 IC 通常在 0.03–0.10，31 天样本连门槛都够不到。**唯一出路是每日累积，没有技巧可绕过。**
3. **对照组（强制）**：每个因子必须同时跑一个「打散版本」——按块循环移位（block shuffle）打乱时间顺序后重算同一套 IC，得到零分布的 `max|IC|`。**报告里的 |IC| 必须超过该零分布分位数才算候选存活。** 这一步是本流程防自欺的核心，不可省略。
4. **去冗余**：因子间 Spearman \|ρ\| > 0.7 视为同簇，簇内保留 IC 最高者。
5. **分割**：前 60% 时间窗选因子（in-sample），后 40% 只看一次（out-of-sample）。**样本外只允许查看一次**，反复查看即等同样本内。
6. **登记冻结**：本表 §2 的因子清单和 §4 的门槛在开跑前冻结。新增因子须另起一节并注明「事后新增」，在报告里与冻结组分开统计。

## 5. 输出要求

每个因子一行，至少包含：因子 ID、样本区间、`n` 与 `n_eff`、IC、零分布门槛、是否存活、分位单调性方向、in/out-of-sample 是否一致。

判决只用三种措辞：**通过**（|IC| 超零分布门槛且样本外同向）、**拒绝**（未超门槛）、**样本不足**（`n_eff` 不足以达到门槛，不给结论）。
