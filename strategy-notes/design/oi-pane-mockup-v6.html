三层在说同一句话 —— 以及我第一次修法时又说了一遍

V4 的五层里,L0 色雾、L1 方向柱、L3 事件车道点亮的是同一批 K 线。本稿先量化这件事,然后展示第一次修法(v5:把车道改成「真值全集密度带」)——它在实测里和 V4 犯了完全同型的错误,与柱子上半区的 Jaccard = 1.000。这个失败反而定位出了根因,并给出唯一自洽的修法。

02第一次修法(v5)及其失败

v5 的想法:既然柱子是 gated 视图,就让车道承载纯符号真值全集——满饱和 = 过门限,低饱和 = 被门限静音,两者的差集直接可见,把冗余层改造成 gateK 的校准仪表。听起来正交。实测不是。

v5 声称低饱和方块是新增信息。但一根指向零轴上方的幽灵柱,本身就是一个被静音的硬 veto——早就画在那里了。
根因是结构性的,不是没调好参数。 真值 veto 的定义是 (Δ价 > 0 ∧ ΔOI > 0) ∨ (Δ价 < 0 ∧ ΔOI > 0),化简即 ΔOI > 0 ∧ Δ价 ≠ 0。浮点价格下 Δ价 == 0 的根数在本样本中是 —,所以「veto」这个键恒等于 sign(ΔOI)——正是柱子的轴向本身。 于是有一条一般性结论:柱子已经完整编码了 (sign ΔOI, |z|, sign Δ价, 是否过门限) 四元量,任何由这四个量导出的逐根图层,都必然是柱子的函数。 L3 车道不该被重新装载,它该被删除。提出这条原则的人第一次修法时照样违反了它,说明这个陷阱不是粗心,是「有一个空通道就想填满」的本能。

03通道重分配(v6)

按上面的结论,逐根层里唯一还能新增信息的,是不能由 1h 柱导出的量。4H 状态符合;RVOL 符合;汇总统计属于状态牌而非逐根层。其余一律删除。

05自检:V6 有没有重蹈覆辙

v5 的教训是:自检指标选错了会放过同型错误。当时用的是 J(色带, 顶带) = 0.147,看起来很独立——但真正该测的是 每个新层与 L1 柱的关系,因为柱子才是那个完备的载体。下面按这个口径重测。

✗ V4 顶部✕ vs 柱上半区(过门限)
—
完全同一集合。这是本稿最初要修的病。
✗ v5 顶带 vs 柱上半区(真值)
—
换了个说法,还是同一集合。这就是为什么 v5 被判失败。
✓ V6 4H 色带 vs 柱上半区
—
—
关于 Jaccard 这个指标本身的局限,说清楚。 J 的可达上界受两个集合的势之比硬约束:色带 60 根、柱上半区 198 根,即使色带完全含于柱上半区,J 也只能到 0.303。所以「J 低」不等于「独立」。 更诚实的口径是 lift = P(柱上半区 | 色带亮) / P(柱上半区),它与集合大小无关。本样本实测 lift = ———接近 1 说明 4H 色带对 1h 柱方向几乎没有预测力,两层确实在说不同的事。 但这也意味着一句反话:所谓「4H 与 1h 同向时本就该共振」在本样本上并不成立。色带值得占用背景通道的理由是它不可由柱导出,而不是它与柱共振。
已知取舍,不藏着。 ① 4H 色带按「最近一根已收线的 4H」判定,最长滞后 3 根 1h——不前视的代价,读者必须知道背景比柱子慢。 ② 4H z 窗口 30 在 1h 图上产生 — 根预热死区,该段永不着色。剔除死区后色带真实墨水预算是 —,不是把死区算进分母的 —。 ③ 白/蓝两种色带在 α≈0.13 下色相判读不可靠(实测两者亮度接近,主要靠色度区分)。已在异色区间交界处加分隔线(本样本 — 处),但方向仍应以状态牌为准。 ④ k_htf 默认 0.8σ 是本样本上的候选,待多品种回测校准。
