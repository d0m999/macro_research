00结论摘要

该指标本质上是一条 自适应周期的 Wilder RSI：用希尔伯特变换估计市场主导周期的瞬时相位推进角，取其半周期作为 RSI 的回溯长度，再用 Hull MA 平滑，最后叠加 TTM 双通道挤压背景与常规背离标记。

四条最需要注意的数学事实：
  1. 前级 4 根 SMA + Detrender 构成一个 −3 dB 带宽仅约 6.25 – 20.5 根 K 线的带通滤波器。周期估计器只能"看见"这个窗口内的周期，超出通带的真实周期会被系统性低估（合成信号实测偏差约 −10 根）。
  2. 脚本用 ta.median(·, 100) 替代了 Ehlers 原版的限幅链（速率限制 + [6,50] 硬钳制 + 指数平滑）。在 BTC 日线上，最终 RSI 周期退化为 1–4 根（中位 3 根），自适应性基本失效，实际平滑由 HMA(21) 承担。
  3. HMA(21) 在长周期段的增益 大于 1（P≈30 处峰值 1.315），因此 RSI 输出可以突破 [0,100]——实测区间为 。
  4. RSI 是有界映射，本质是 logistic 压缩：RSI = 100·σ(ln(Su/Sd))。σ 在两端饱和，导致 钝化。本指标因 N 退化到 1–4 根，base_rsi 有 的时间贴在 [0,3]∪[97,100] 的死区（详见第 13 节）。

把脚本 203 行压缩成一条单向的计算图。注意两条支路的耦合点：周期估计支路决定 RSI 的 N，挤压支路完全独立、只负责背景着色。

02第 0 步：4 点预平滑

式 2-1　priceSmooth（脚本第 68 行） priceSmooth[t] = ¼ · ( p[t] + p[t−1] + p[t−2] + p[t−3] )

这是长度 4 的矩形窗 FIR（等权滑动平均）。令 z = ejω，ω = 2π/P（P 为周期，单位：根 K 线）：

式 2-2　频率响应 HSMA4(ω) = ¼(1 + z−1 + z−2 + z−3) = e−j1.5ω · sin(2ω)4·sin(ω/2)
  • 零点：sin(2ω)=0 ⇒ ω = π/2 与 π ⇒ 在 P=4 与 P=2 处完全归零（4 根以下的噪声被彻底抹掉）。
  • 群延迟：1.5 根（由 e−j1.5ω 给出），线性相位、无相位失真。
  • 作用：希尔伯特变换对高频混叠极敏感，先用 4 点窗把 2–4 根的噪声压掉，是 Ehlers 的标准预处理。

03第 1 步：Detrender —— 去趋势 + 90° 移相

式 3-1　detrender（脚本第 71–74 行） det[t] = 0.0962·ps[t] + 0.5769·ps[t−2] − 0.5769·ps[t−4] − 0.0962·ps[t−6]

这四个系数来自 Ehlers 的希尔伯特变换核。关键不在于数值本身，而在于它的代数结构：系数反对称（首尾互为相反数），因此可以做因式分解。令 w = z−2：

式 3-2　因式分解 H(z) = 0.0962 + 0.5769w − 0.5769w2 − 0.0962w3 = (1 − w) · ( 0.0962w2 + 0.6731w + 0.0962 )

第二个括号在 w 域是对称的（0.0962, 0.6731, 0.0962），代入 w = e−j2ω 后化为纯实数。第一个括号 (1 − e−j2ω) = 2j·sin ω · e−jω。于是：

式 3-3　极坐标形式（本节核心结论） Hdet(ω) = j · e−j3ω · 2·sin(ω)·[ 0.6731 + 0.1924·cos(2ω) ]

  ↑ 90° 移相（希尔伯特变换的定义性质）   ↑ 3 根群延迟   ↑ 实的幅度函数 G(ω) ≥ 0

三个推论：

  1. 去趋势：ω→0 时 sin ω→0，直流分量（趋势）被完全抑制，−6 dB/oct 滚降。
  2. 90° 移相：前面的 j 意味着输出相对输入超前 90°——这正是构造解析信号所需的正交分量。
  3. 群延迟恰好 3 根：所以脚本第 77 行写 I1 = detrender[3]——把同相分量人为延后 3 根，去对齐 Q₁ 的固有延迟，二者才构成正确的正交对。

04第 2 步：构造希尔伯特正交对 (I₁, Q₁)

式 4-1　脚本第 77–81 行 I₁[t] = det[t−3]     Q₁[t] = 0.0962·det[t] + 0.5769·det[t−2] − 0.5769·det[t−4] − 0.0962·det[t−6]

Q₁ 用的是与 Detrender 完全相同的核，只是输入换成 detrender 本身。设 det[t] = A·cos(ωt)，由式 3-3：

I₁[t] = A·cos(ωt − 3ω)  ≡  A·cos Ψ
Q₁[t] = A·G(ω)·cos(Ψ + 90°)  ≡  −A·G(ω)·sin Ψ

即 z1 = I₁ + jQ₁ = A·e−jΨ —— 一个随时间匀速旋转的相量。每根 K 线转过的角度就是 ω = 2π/P。测出这个角速度，就得到了周期。

数值验证

对纯正弦输入（无趋势、无噪声）在稳态区间做最小二乘投影，分别拟合 I₁ 与 Q₁ 的相位和幅度：

真实周期 P∠Q₁ − ∠I₁幅度比 G = |Q₁|/|I₁|椭圆度 ε=(1−G)/(1+G)结论

表 1　正交性验证。相位差恒为 +90°，与式 3-3 完全吻合，希尔伯特正交对成立。

但幅度比 G 随周期急剧衰减（P=20 时仅 0.512）。因为 I₁ 是 detrender 直接延迟（增益 1），而 Q₁ 又过了一遍 Detrender 核（增益 G<1）。这使相量轨迹从圆退化为椭圆，可分解为：
z1 = A·[ 1+G2·e−jΨ + 1−G2·e+jΨ ]
第二项是反向旋转分量，会以 2ω 的频率污染相位估计。P=20 时反向分量占比已达 32%，P=60 时达 68%——这是瞬时周期剧烈抖动、并频繁出现"负频率"读数的数学根源。

05第 3 步：差分相位 → 瞬时周期

脚本第 83–91 行看着突兀（I2 = I1 − jQ、Q2 = Q1 + jI），其作用是构造一个相量，使其相位对常数偏移免疫。用复数一步写出：

式 5-1　相量合成 z2 = I₂ + jQ₂ = (I₁ − jQ) + j(Q₁ + jI) = z1 + j·z1[t−3] = z1·( 1 + j·ejθ )，其中 θ = 3ω
式 5-2　相位 arg(z2) = arg(z1) + arg(1 + j·ejθ) = −Ψ + θ2 + π4

关键：后两项在 ω 恒定时是常数。相邻两根 K 线做差，常数项完全抵消：

式 5-3　差分相位（脚本第 89–98 行） Δψ = arg z2[t] − arg z2[t−1] = −ω

Re = I₂·I₂[1] + Q₂·Q₂[1] = |z₂|·|z₂[1]|·cos(Δψ)   （点积）
Im = I₂·Q₂[1] − Q₂·I₂[1] = |z₂|·|z₂[1]|·sin(ω)   （叉积的负值，符号与旋转方向一致）

Δφ = atan2(Im, Re) = ω  ⟹  Praw = 360° / Δφ

脚本第 59–63 行的 f_atan2 是手工实现的四象限反正切（Pine 的 math.atan 只返回 (−90°,90°)）；第 93 行 phaseAngle < 0 ? +360 把角度折回 [0,360)；第 96 行 math.max(phaseAngle, 1.0) 是唯一的防护——把 Praw 上限锁在 360。

这里缺少 Ehlers 的两道保险。Ehlers 原版 MESA 在算出 InstPeriod 后会做：速率限制（单根变动不超过 ±50%）、硬钳制 [6, 50]、指数平滑 (0.25/0.75)。本脚本只做 phaseAngle ≥ 1° 的下限，于是 Δφ 可以落在 (180°, 360°)，对应负角速度——相量在倒转，物理上无意义。实测 BTC 日线有 的样本落在 P∈(0,2) 这个"负频率"区间。

06第 4 步：median(100) 与半周期

式 6-1　脚本第 99–100 行 market_frequency = ta.median(Praw, 100)    period = int(market_frequency / 2)

滚动中值是次序统计滤波器：对脉冲噪声免疫（单个离群值无论多大都不影响中位），这正是它替代 Ehlers 限幅链的动机。代价是：对阶跃变化需要窗口内过半样本翻转才响应，最坏滞后 ≈ 50 根 K 线，且输出呈阶梯状。

除以 2 是 Ehlers 的惯例：RSI 的测量窗口取主导周期的一半。理由是 RSI 度量的是上涨/下跌力量的比值，一个完整周期会把两个方向的运动平均掉，半周期恰好覆盖一次单向摆动。

07第 5 步：Wilder RSI（自适应 N）

式 7-1　脚本第 45–55 行（手写 RSI） u[t] = max(x[t] − x[t−1], 0)    d[t] = max(x[t−1] − x[t], 0)
Su[t] = α·u[t] + (1−α)·Su[t−1]，  α = 1/N   （Sd 同理）

RSI = 100 − 1001 + Su/Sd = 100 · SuSu + Sd

α = 1/N 正是 Wilder 平滑（Pine 的 ta.rma），而非 EMA（EMA 用 α = 2/(N+1)）。因此这段手写代码在数学上等价于 ta.rsi(close, N)，但有一处实质差异：

启动瞬态。脚本用 nz(sum_u[1]) 从 0 起递推，没有 Ehlers 的 for 循环种子，也没有 ta.rma 的 SMA 播种。递推 S[t] = α·u + (1−α)·S[t−1] 从 0 收敛到稳态需要约 3N 根。在 BTC 日线上 N 只有 1–4，问题不大；但若用于 N 较大的品种/周期，前 3N 根 RSI 会系统性偏低，需自行丢弃预热段。

另需注意：Pine 中 1 / y（两个 int 相除）返回浮点；若为整数除法，α 在 N≥2 时会截断为 0、指标完全失效——由指标可正常运行反推，此处为浮点除法。但当 market_frequency < 2 时 period 会被 int() 截断为 0，造成除零（本次 300 根样本中出现 次）。

三段都是加权移动平均的线性组合，因此 HMA 整体仍是线性 FIR，可展开为 24 个抽头的固定权重（21 + 4 − 1），权重和为 1。

09第 7 步：双通道挤压（TTM Squeeze）

式 9-1　脚本第 111–124 行 BB:  Basis = SMA(close, 20)， Dev = 2·σpop(close, 20)
KC:  Basis = EMA(close, 20)， Dev = 1.2·ATR(20) = 1.2·RMA(TR, 20)

isSqueeze = (BBupper < KCupper) ∧ (BBlower > KClower)   ⟺   BB 完全落在 KC 内部
squeezeFired = isSqueeze[1] ∧ ¬isSqueeze   （挤压释放 = 波动率突破）

数学含义：BB 宽度 ∝ 标准差（对离群值敏感，平方加权），KC 宽度 ∝ 平均真实波幅（一阶矩，稳健）。两者宽度比 = 2σ / 1.2·ATR。当波动被压缩、价格密集时，σ 收缩得比 ATR 更快（因为 σ 对窄幅震荡更敏感），BB 缩进 KC 内部 → 判定为挤压。默认参数下 σ/ATR ≈ 0.6 是临界点。

注意：该支路完全独立于 RSI 支路，读的是 close，不参与任何 RSI 计算，仅在第 188 行用 fill() 在 20–80 之间画背景色。因此"挤压 + RSI 超卖"是两个正交条件的叠加，而非一个联合信号。

13钝化：有界指标的饱和

定义

钝化指摆动指标在强趋势中长时间停在超买/超卖边界附近，价格继续朝原方向推进，指标却几乎不再变化，因而丧失分辨能力、并反复给出错误的反转信号。它不是"指标算错了"，而是有界映射在边界处的导数趋近于零——一个纯粹的数学后果。

式 13-1　RSI 的等价形式（本节核心） 令 L = ln( Su / Sd )  （多空力量比的对数，即 logit）

RSI = 100 · SuSu + Sd = 100 · eL1 + eL = 100 · σ(L)   其中 σ 是 logistic sigmoid

RSI 就是对多空力量比取对数后，再做一次 logistic 压缩。而 σ′(L) = σ(1−σ)，在 |L|→∞ 时趋于 0——这就是钝化的全部机理。

式 13-2　灵敏度函数 d(RSI)dL = 100·σ(1−σ) = RSI·(100 − RSI)100

这是一条以 RSI=50 为顶点、峰值 25、两端趋于 0 的抛物线。含义极其直接：

  • RSI=50 处，力量比每变化 1%，RSI 移动 0.25 点；
  • RSI=95 处，力量比要再变化 约 5 倍，RSI 才能移动 5 点；
  • RSI=99 处，灵敏度只剩 0.99，比中点低 25 倍——价格继续上涨，RSI 基本不动。

图 12　RSI = 100·σ(L) 的 S 形压缩。灰色为钝化区（|L| > 2.2，即 RSI > 90 或 < 10）。L 从 +2.2 走到 +5（力量比再翻 15 倍），RSI 只从 90 挪到 99.3。

两个直接推论。
  1. base_rsi 有 41.5% 的时间贴在 [0,3]∪[97,100]，几乎一半时间处于死区——这是 N 退化到 1–4 根的直接后果（N 越小，Wilder 平滑越弱，RSI 越容易冲到边界）。对照 RSI(14) 该比例为 0%。
  2. HMA(21) 在这里的真实作用不只是平滑：它把极端值从边界拉回，使死区占比从 41.5% 降到 2.2%。换言之，是 HMA 让这条 RSI 重新变得"可读"，代价则是第 8 节的过冲越界。

如何解钝化

方法做法代价
logit 变换直接以 L = ln(RSI/(100−RSI)) 作指标，灵敏度恒为 1，数学上完全消除饱和RSI 极端时 L→±∞，需截断；直观性下降
趋势过滤ADX / 均线斜率判定强趋势时，停用超买超卖信号，改走趋势跟随引入额外参数与主观阈值
动态阈值用该品种 RSI 的历史分位数（如 95 分位）替代固定 80需要足够长的样本，且分布非平稳
延长时间窗增大 N（本例中 N≥14 即基本消除死区）滞后增加，信号变少
改用无界指标MACD、ROC、价格对均线的标准差偏离等失去统一的 [0,100] 标尺

注：钝化与"滞后"是两件事。滞后是相位延迟（本脚本的 median(100) 属此类），钝化是幅度饱和（有界映射的固有性质）。强趋势中两者常同时出现，但 remedies 不同。
