## Oracle 的点位到底有多少（2026-09-17 追加）

- 用户追问「oracle 的数据没有吗」→ 查实：**SOLVE 全库可得的 14 期 IG/HY 报告里 ORCL 只出现 1 次**。
  - 唯一 SOLVE 点：**2025-08 = 43bp**（前值 2025-07 = 39bp，出自 2025-08 期 IG 榜单第 6 名，+5bp / +11.9%）。
  - 已核未出现：2025-12 IG + HY、2026-01 HY、2026-01~08 IG、2026-07/08 HY —— 全部无 ORCL。
  - 缺档：2025-09/10/11 三期站上 404 —— **恰好覆盖 Oracle 43 → 103bp（2025-11-14 媒体值）的整段跳升**。
- **关键辨析（已写进 skill）**：Oracle 落榜**不能**像 Broadcom 那样当作证伪。原因是 SOLVE 榜单按
  **月末 vs 月末**排序，而 Oracle 2025-12 是「128 → 141（盘中）→ 126」的 V 形回撤，月末回到月初 → 月环比≈0 → 自然落榜。
  → 落榜能证伪「月度量级」的数字，证伪不了「期间极值」的数字。
  → 反过来，「落榜」本身可当**约束**用：月环比 < 当月第十名门槛（2025-12 IG 为 +3.7bp）。
  → 判断落榜是否构成证伪，**必须先确认该名在数据商宇宙内**（要有相邻月份的数据行）。
- **对 Problem 3 的影响**：不改结论（157bp 无出处 / 「2009 年以来」），但**强化**——公开点位比原判更稀，
  个位精度的月度引用一律按不可复核处理。

## 19:5x 供需缺口读法（图 `supply-demand-gap-2024-2027.png`）

用户问「看这两张图怎么看出供需缺口」。**准确答案是：看不出——两张原图都没画缺口**，
它们只把需求与供给并排放在同一条年份轴上。补了一步减法并单独成图。

- **缺口只能在无量纲的增速空间里算**：`缺口 = 需求增速 − 有效供给增速`，单位 pp。
  金额（百万美元）与物理量（片/月、bn Gb）的水平值相减没有量纲意义。
- **有效供给取互补品的 min**（CoWoS 与 HBM 缺一个都出不了 GPU ⇒ 取 min，不能取平均）。
  取平均会系统性高估供给能力。**这是全图唯一容易搞反的一步。**
