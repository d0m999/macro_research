### 关键数学结论（可复用的研究结论）

1. Detrender 核 (0.0962, 0, 0.5769, 0, −0.5769, 0, −0.0962) 可因式分解为
   H(z) = (1−z⁻²)(0.0962z⁻⁴+0.6731z⁻²+0.0962) = **j · e^(−j3ω) · 2sin(ω)[0.6731+0.1924cos2ω]**
   → 90° 移相 + 3 根群延迟 + 实幅度函数。这是 `I1 = detrender[3]` 的存在理由。
2. 与 4-tap SMA 级联后 −3 dB 通带仅 **6.25–20.5 根**，峰值增益 0.663 @ P=10。
   周期估计器只能看见通带内的周期，通带外真实周期被系统性低估（合成 chirp 偏差 ≈ −10 根）。
3. 数值验证：∠Q₁ − ∠I₁ 恒为 **+90°**（P=6…60），正交性成立；但幅度比 G 随周期衰减
   （P=20 时 0.512），相量退化为椭圆，反向旋转分量占比 (1−G)/(1+G) 在 P=20 达 32%。
4. 脚本用 `ta.median(P_raw, 100)` 取代了 Ehlers 的限幅链（±50%/根速率限制 + [6,50] 硬钳制 + 0.25/0.75 平滑），
   且只做 `phaseAngle ≥ 1°` 下限 → Δφ 可落在 (180°,360°) 即"负频率"。

## 钝化（指标饱和）—— 概念梳理与量化

- 定义：摆动指标在强趋势中长期停在超买/超卖边界，价格继续走而指标几乎不动，丧失分辨能力。
- 数学本质（可复用结论）：**RSI = 100·σ(ln(S_u/S_d))**，σ 为 logistic sigmoid。
  - 灵敏度 **dRSI/dL = RSI(100−RSI)/100**，是以 RSI=50 为顶点、峰值 25、两端归零的抛物线。
  - RSI=50 → 25；RSI=80 → 16；RSI=95 → 4.75；RSI=99 → 0.99（比中点低 25 倍）。
  - logit L = ln(RSI/(100−RSI))：RSI=80→+1.39，95→+2.94，99→+4.60。
- 解钝化：logit 变换（灵敏度恒为 1，数学上完全消除饱和）/ 趋势过滤 / 动态分位阈值 / 增大 N / 改用无界指标。
- **钝化 ≠ 滞后**：钝化是幅度饱和（有界映射固有），滞后是相位延迟（如 median(100) 的 50 根）。
- BTC 日线实测（300 根）死区占比（RSI∈[0,3]∪[97,100]）：
  base_rsi(N 自适应 1–4) **41.5%** ／ rsi_v(+HMA21) 2.2% ／ RSI(2) 9.1% ／ RSI(14) 0% ／ RSI(21+) 0%。
  → N 越小钝化越严重；HMA(21) 的真实作用之一是把饱和值拉回可分辨区间。
