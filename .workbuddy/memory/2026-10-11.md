## tradermonty/claude-trading-skills 是什么（用户追问，已读 README 全文核实）

**不是交易库**（无 Python 回测框架），是 **78 个 SKILL.md 工作流包**。作者 TraderMonty 的个人项目
（README 自称 "first for self, open for others"），英日双语，有文档站 tradermonty.github.io。
定位：时间有限的个人投资者，**core-satellite 结构**（核心=长期/ETF/股息，卫星=纪律化 swing）。
明确不做信号服务/自动下单/scalping；目标是「市场复盘 → 风控 → 交易计划 → 日志 → 改进」的流程化。

流派地图（README 点名的方法论来源）：
- O'Neil / IBD：canslim-screener、ftd-detector、ibd-distribution-day-monitor
- Mark Minervini：vcp-screener、breakout-trade-planner（+ market-top-detector 里的 Leading Stock Deterioration）
- **StockBee（5 个，最成体系的短线段）**：momentum-burst / exhaustion-hammer / episodic-pivot /
  20pct-study / setup-fluency-trainer
- **Jason Shapiro 逆向 COT（4 个，完整流水线）**：cot-contrarian-detector → news-reaction-failure-analyzer
  → contrarian-setup-gate → futures-position-sizer
- Druckenmiller 宏观：stanley-druckenmiller-investment（整合 8 个上游 skill 出 0-100 conviction）、macro-regime-detector
- Kanchi 股息（日系，3 个）：sop / review-monitor / us-tax-accounting
- 事件驱动：pead-screener、earnings-trade-analyzer；统计套利：pair-trade-screener（协整+z-score+半衰期）
- 量化研究：backtest-expert、manifoldbt-backtester、edge-* 8 个流水线、
  residual-edge-analyzer（HAC 回归拆「基线暴露 vs 残差 alpha」）、strategy-pivot-designer
- 风控闸门：exposure-coach、drawdown-circuit-breaker、pre-trade-discipline-gate、position-sizer
- 其他：options-strategy-advisor（BS）、crypto-regime-analyzer、institutional-flow-tracker（13F）、
  us-market-bubble-detector（Minsky/Kindleberger v2.1）

数据依赖：FMP 为主（免费 250 req/天，多数 screener 够用）、FINVIZ Elite 可选（$39.5/月）、
Alpaca 仅 portfolio-manager 与日内 bar。**5 个 starter skill 完全免 key**：
market-breadth-analyzer、uptrend-analyzer、position-sizer、trader-memory-core、signal-postmortem。
skill 有 production / beta 状态分级，StockBee 系与 edge 部分多为 beta。

### FMP 账号与采购事实（官方一手，注册/付费决策用）

- 注册**只要邮箱 + 密码**（或 Google 登录），**不要电话、不要信用卡**；官方 how-to 原文：
  "Creating your initial account doesn't require any credit card, bank account, or other sensitive information."
- 免费档 Basic **无限期**（不是试用窗口），250 次/天，超额返回 429 硬停、**不可能产生扣费**（无卡在档）。
- 付费走 **Stripe**（借/贷卡），Enterprise 才支持银行转账。**中国大陆发行卡能否过 Stripe 未证实。**
- ⚠️ ToS §4.6 **No Refunds**：所有销售最终，不退款。订阅前先用免费档验证数据覆盖。
- 免费/个人档 = Personal Use Only；展示或再分发需单独 Data Display & Licensing Agreement（商业档表单要填 Country of Registration）。
- 本机实测（2026-10-11）：`financialmodelingprep.com` 直连可达（无 key 请求返回 401 说明网络通）；
  `site.financialmodelingprep.com` 网页端对 curl 返回 403（CloudFront 拦 UA，非网络阻断）。
- **"一次 API call" 的官方定义**：一次 HTTP 请求 = 1 call，**与返回字段数无关**；一个请求可带
  多 symbol + 日期范围，返回整批 JSON。免费档另有硬规则 "Maximum limit of 5 for all endpoints"
  = 单请求最多返回 5 条记录 ⇒ 免费档实际吞吐上限 ≈ 250×5 = 每天 1,250 条记录。
- **未证实**：ToS 中是否存在针对特定国家/地区的限制条款（未逐条通读全文）。
