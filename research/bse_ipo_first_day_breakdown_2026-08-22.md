# 北交所 IPO 上市首日破发统计研究

> 截至日：2026-08-22｜数据快照：2026-08-22T06:48:15Z｜研究范围：北交所相关 IPO 记录与上市首日名义收盘价

## 结论先行

- **广义“全部上市事件”口径：343 只，首日破发 87 只，占 25.3644%**。另有首日收盘等于发行价 26 只，高于发行价 230 只。该口径把原精选层/新三板精选层后来转入北交所的股票也纳入，因为官方代码对照表把其原挂牌日期作为“上市日期”。
- **严格“北交所原生 IPO”口径：272 只，首日破发 59 只，占 21.6912%**。这里从北交所正式开市日 2021-11-15 起算，排除此前已经在精选层挂牌、后转入北交所的 71 只。若问题中的“北交所 IPO”强调北交所成立后的公开发行，建议采用这一数字。
- 判断规则：`首日收盘价 < IPO发行价` 才算破发；相等不算破发；未做复权，也不使用上市后的任何价格。

## 数据入口与一手来源核验

### 1. 北交所官方名录入口

- [北交所股票列表](https://www.bse.cn/nq/listedcompany.html)：官方页面，页面通过前端请求加载股票列表。根据页面实现及公开客户端对其请求的复核，相关 POST XHR 入口为 `https://www.bse.cn/nqxxController/nqxxCnzq.do`，典型参数为 `page=0&typejb=T&xxfcbj[]=2&xxzqdm=&sortfield=xxzqdm&sorttype=asc`。可见字段包括证券代码、证券简称、上市日期、总股本、流通股本、所属行业、地区、报告日期等。
- [北交所新旧代码对照表](https://www.bse.cn/service/code_mapping.html)：官方页面明确提示，原精选层平移进入北交所的公司，其“上市日期”字段为原精选层挂牌日期。这是区分广义口径和严格北交所 IPO 口径的关键。
- [北交所股票行情](https://www.bse.cn/nq/quotation.html) 与 [北交所统计数据](https://www.bse.cn/static/statisticdata.html)：官方行情/统计页面入口，但本轮环境对 `www.bse.cn` 页面和 XHR 返回了 WAF `403 Forbidden` 或重定向循环，未将页面不可抓取误判为没有数据。

### 2. 北交所官方行情字段定义

- [北交所数据文件接口规范（2025-12-31 版本）](https://www.bse.cn/uploads/6/file/public/202512/20251231195329_x6is9o1b6p.pdf)：定义日终静态行情文件 `bj_securityclosemd_YYYYMMDD.dbf`，其“证券收盘行情”包含证券代码、昨日收盘价、今日开盘价、最高成交价、最低成交价、最近成交价等字段；这说明官方批量历史行情的权威形态是交易所日终行情文件，而不是新闻或二手统计。
- [北交所交易规则](https://www.bse.cn/jygl_list/200028217.html)：第 3.3.12 条规定向不特定合格投资者公开发行的股票上市交易首日无价格涨跌幅限制；第 4.1.2 条定义收盘价：通常由收盘集合竞价产生，不能产生时取最后一笔成交价，当日无成交取前收盘价；第 5.2.3 条规定 IPO 上市首日即时行情前收盘价显示为发行价。

### 可能遗漏或口径风险

- **官方批量行情文件的公开获取限制**：北交所官方数据文件规范定义了日终收盘行情文件，但本轮未取得逐日官方 DBF 文件；首日收盘价实际采用上面的可公开访问结构化 IPO 数据入口。因此报告是“官方规则/字段定义 + 可复核机器数据”的组合，不把东方财富说成北交所官方数据。
- **原精选层转入股票**：官方代码对照表的上市日期不是北交所新 IPO 日期。若问题只问“北交所打新”，应使用严格口径 59/272=21.6912%；若问“北交所板块内全部曾上市证券的首日表现”，可使用广义口径 87/343=25.3644%。
- **退市/风险警示状态**：广义表保留历史 IPO 记录，即使当前简称带 `退` 或 `*ST`；“截至日仍在北交所挂牌”的状态口径已另用北交所官方股票列表做左连接，见上面的 338 只统计。
- **当前列表核对**：本次已通过北交所官方股票列表接口（`https://www.bse.cn/nqxxController/nqxxCnzq.do`，`xxfcbj[]=2`）完成状态左连接；因此上面的 338 只当前列表口径不等同于广义历史口径。
- **简称变更**：表中的简称是数据快照简称，不一定是上市首日简称；统计不受简称变更影响。
- **前复权/后复权**：本题比较发行价和上市首日收盘价，必须使用未复权的首日价格；不得用今天的前复权 K 线倒推。
- **截至日之后的新股**：原始 API 还有 3 条仅有发行价的北交所记录，未纳入统计；如果其后上市，需重新抓取并追加首日价格。
