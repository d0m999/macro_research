### Jev 的输出范式（决定怎么写调用）

三种原语，全部返回**校准概率**而非文本，每个答案另带独立 `confidence`：

- `noul` — 是/否，返回 0–1 概率
- `choice` — 从你给的选项里选一个（≤255 项），返回选中项 + **每个选项的概率分布**
- `score` — 在有序档位上打分，返回分值 + 每档概率

**一个请求里可以并行问多个问题**（共享同一份 `state`）。这一点是整个方案能跑进 87 秒的关键（见下）。

## 作者自述的实施路径（原文拆解）

1. **数据源**：NewsHub（作者自己的站 `wqu.guru/newshub`）攒了三个月的投资日报，
   成品页 `https://wqu.guru/newshub/daily?topic=invest`，**一天一份**（77 份投研日报）。
2. **判断**：一天一份日报 + 当前持仓 → 丢给 OpenRouter 上的 Jev 1.13
   → 每个标的输出「买 / 卖 / 不动」+ 三个选项的概率与置信度。
3. **回测引擎（纯代码，无模型）**：拿这些概率调仓 → 按 **Binance 真实小时级 K 线**成交
   → 算净值 → 对账。
4. **可视化**：把**可视化设计稿**丢给 Ling-3.0-flash-VL，让它照着写前端。
   **没给设计稿标注，也没给组件库** —— 它自己看图，直接构建出动态仪表盘页面：
   净值曲线、三个策略的持仓条、当日决策流、右上角的加速倍数。
5. **出片**：用 **playwright 逐帧截图**，390 帧压成 13 秒（画面标注「回放加速 8.3x · 本片 10.5s 放完」，
   实际文件 14.3s）。

## 判断依据来自哪里（2026-09-21 实测其日报页）

**Jev 本身不带策略，它只是判断器。** 实测 `https://wqu.guru/newshub/daily?topic=invest`
（公开可访问，HTTP 200）看到的日报真实形态：

- **每早 8:00 出报**（页面标注「更新于 08:01」）⇒ 固定的信息截止时点
- **本期 130 个事件，覆盖 17 家信源** ⇒ 一条多源交叉验证的筛选链
- 阅读结构分三层：
  1. **今日头条 · Lead** —— 系统写的一段综述，把当日主线串起来。
     实测样例（2026-09-20）：「美联储宣布自 2023 年以来首次加息……中东局势持续恶化……
     加密市场方面 Polymarket 遭欺诈攻击、FET 跨链被盗等风险事件密集，行业安全与合规问题再度凸显。
     资本市场整体呈现避险与分化并存的格局。」
  2. **本期要目** —— 5–6 条精选，每条带时间戳 + 一个两位数字编号（03 / 02 / 03 / 01 / 03 / 05）
  3. **分板块事件流** —— 逐条给：时间戳 · 信源 · **关联 N 源** · 标题 · 摘要 · 话题标签
- 板块：AI / Invest / Biz / Ship / Collab（回测用的是 Invest 栏）

⇒ **投资观点是在「编报」这一步形成的，不是 Jev 形成的。** Jev 只负责把已经写好的观点
翻译成概率。真正的策略载体是日报的「信源选择 / 事件合并（关联 N 源）/ 要目排序 / 综述写法」。

⚠️ 「本期要目」旁那个两位数字的确切含义**未确认**——页面在别处会显式写「关联 6 源」，
  推测该数字是同一指标（交叉验证源数），但**未证实**，不要当结论用。

### 三路输入，只有两路可改

| 输入 | 内容 | 你能改吗 |
|---|---|---|
| ① `state` | 日报正文 + 当前持仓 | ✅ 你构造 |
| ② `criteria` | 买 / 不动 / 卖 的语义定义 | ✅ 你写 |
| ③ 模型权重 | RLCD 训练得来，全部账户共享同一套 | ❌ 不可微调 |

而「文本 → 概率」这个映射本身**在权重里，不可读、不可改**。这是它与传统量化的根本区别：
传统量化的策略是人写的规则，可读可改；这里的策略被拆成「**喂什么料 + 怎么问**」，
剩下那段是黑箱。

### 一个佐证

作者把 Jev 换成 qwen3.7-flash 重跑，**其他全不变**，三个策略的相对排序就变了
（动量 6.94→7.54、逆向 −0.99→−2.82、宏观 −10.51→+0.69）。
⇒ 说明「判断策略」里属于模型的那部分权重很大，不是流水线决定的。

### 推测：三个策略怎么来的

他用同一个模型跑出「动量 / 逆向 / 宏观」三个策略 ⇒ **合理推断是三套 state / criteria
的构造方式，而不是三套代码**。⚠️ 他未公开 prompt，此为推断，未证实。

| 项 | 值 |
|---|---|
| 账户 | 3 个，各 $100,000（每策略一个独立账户） |
| 区间 | 77 天日报 |
| 策略 | 3 个：动量 / 逆向 / 宏观 |

| 总成本 | **$0.09**（Ling 免费，所以基本全是 Jev） |
| 实跑耗时 | 87s，1.12s / 次，3 并发 |
| 失败数 | 0 |

**我做的两处自洽性验算（都通过）**：

- **调用次数**：1155 决策 ÷ 5 标的 = **231 次调用** = 77 天 × 3 策略 ✓
  ⇒ 每次调用是一个 (日, 策略) 对，用 Jev 的「并行多问题」一次性问 5 个标的。
  也解释了为什么 231 × 1.12s ÷ 3 并发 ≈ **86s ≈ 87s**（若按 1155 次调用则要 431s，对不上）。
- **单次 token 量**：$0.09 ÷ 231 = $0.00039/次；÷ $0.042/M ≈ **9.3K tokens/次**
  —— 一份日报正文 + 5 个标的持仓 + 5 个问题，量级合理。

3. **未公开**：给 Ling 的 prompt、那张设计稿、回测代码、日报原始 JSON。

### 步骤

**Step 1 · 判断腿（Jev）**

```bash
# 直连 TypeSafe：POST /v1/systemone（Python SDK: typesafe_sdk.TypeSafeClient）
# 或走 OpenRouter Decisions API：
#   POST https://openrouter.ai/api/alpha/decisions
#   { "model": "typesafe/jev-1.13", "state": <当天日报全文 + 当前持仓>,
#     "questions": { "<ticker>": { "type": "choice",
#                                  "instructions": "未来一日该标的应买入、卖出还是不动？",
#                                  "criteria": { "buy": "...", "sell": "...", "hold": "..." } }, ... } }
```

要点：
- `state` 放**日报正文 + 持仓快照**（作者单次约 9.3K tokens）；`questions` 放 5 个标的
  （或再加 `noul` 做「是否触发风控」、`score` 做「信号强度」）。
- 响应在 `answers` 里：`choice` 取选中项 + `probabilities` 全分布 —— **后面的调仓逻辑吃的是概率，不是标签**。
- **Jev 不能算数、不能比日期、不看图**。所有数值运算、成交撮合、净值计算都留在自己代码里。
- 32K 上下文是硬约束，日报要控制长度。

**Step 2 · 回测引擎（自写，无模型）**
- 概率 → 目标仓位（需要你自己定映射规则：阈值 / 按概率加权 / Kelly，作者没说）
- 按 Binance 小时级 K 线成交（滑点、手续费口径自定），算净值曲线、对账
- 建议同时跑等权买入持有基准 —— 这是作者自己给出的、最有价值的一条对照

**Step 3 · 展示腿（Ling-3.0-flash-VL）**
- 输入：**一张静态设计稿**（Figma/截图皆可）+「照这个写一个可运行前端」的指令。
  设计稿本身可以由 LLM 先生成，作者没说来源。
- 关键条件：**不给标注、不给组件库** —— 让模型自己从像素里读出版式与信息层级。
  这正是 Ling-3.0-flash-VL 的强项（官方主打 image-to-web code，带视觉反馈闭环
  「观察→行动→验证→修正」，Image-to-WebDev Arena 上以 5.5B 激活超过 GPT-5.4）。
- 产出：单页动态仪表盘，把回测 JSON 渲染成**时间轴回放**（净值曲线 + 每策略持仓条 +
  当日决策流 + 当日新闻 + 加速倍率），而不是静态报表。

**Step 4 · 出片**
- playwright 无头打开仪表盘 → 用 `page.evaluate` 驱动时间轴前进 → 逐帧 `screenshot()`
  → ffmpeg 合成 mp4。作者给的口径是 **390 帧 ≈ 13s**（约 30fps）。
- 提速技巧：正文里放「回放加速 Nx」角标，让观感上 77 天压缩到十几秒而不显得跳。

### 最小可验证版本（建议先做这个）

先用**一个策略、两个标的、10 天**跑通闭环：
自有日报 → Jev `choice` 出概率 → 简单阈值调仓 → 净值曲线 → Ling 把设计稿变成一页
HTML → playwright 录 3 秒。跑通后再横向扩到 3 策略 × 5 标的 × 77 天。
