日期：2026-09-26。范围：AI 资本开支、半导体供需、光通信。状态：首轮定性样本蒸馏，详细核验见本目录 `validation.json` 与 `review-notes.md`。

## 先读结论

**这批样本中，两人都从产业需求追到供给与利润，并把融资条件纳入选择。最值得比较的是具体检查顺序，以及对周期利润、商业化阶段和现金回收的权重。**

- **Herman Jin** 经常从使用方式变化出发，解释 token、存储和 CPU 需求，再与扩产节奏、实际交付和市场预期比较。他会同时保留产业看好、短期利润受限或当前价格不合适的判断。
- **Serenity** 经常把需求沿具体产品、材料、设备和客户关系逐层传递，再检查公司究竟靠什么赚钱、何时兑现，以及融资是否侵蚀现有股东的收益。
- 两种概括都是对所选案例的归纳。它们有大量共同部分，不能将人固定为“只懂宏观”或“只懂技术”，也不能据此判断谁投资更成功。

证据：Herman 的需求链 [HJ-001](herman-jin-cases.jsonl:1)、[HJ-002](herman-jin-cases.jsonl:2)，交付与估值 [HJ-010](herman-jin-cases.jsonl:10)、[HJ-015](herman-jin-cases.jsonl:15)、[HJ-016](herman-jin-cases.jsonl:16)；Serenity 的链条和口径 [SR-011](serenity-cases.jsonl:11)、[SR-013](serenity-cases.jsonl:13)、[SR-020](serenity-cases.jsonl:20)，融资 [SR-003](serenity-cases.jsonl:3)、[SR-006](serenity-cases.jsonl:6)、[SR-027](serenity-cases.jsonl:27)。

## 2. 思考模型：先看核心，再看分支

### Herman Jin

| 方法 | 典型路径 | 本轮判断 |
|---|---|---|
| HJ-M01 使用行为到物理需求 | 使用方式 → token/数据/调用 → 硬件需求 → 供给扩张速度 | 样本内支持；定性路径，不是已验证的指数增长公式 |
| HJ-M02 瓶颈与交付 | 拆具体环节 → 比较配额、产线切换、良率 → 判断交付与补产能时间 | 样本内支持；不能推广成所有追赶者都会受益 |
| HJ-M03 现金收付 | 变现途径 → 建设与收入滞后 → 谁反复融资、谁先收款 | 样本内支持；其风险判断的强度随时间变化 |
| HJ-M04 利润性质与预期 | 利润来自迭代还是涨价 → 能持续多久 → 市场计入多少 → 采用何种估值口径 | 样本内支持；没有固定通用的 PS/PB/PE 倍数表 |
| HJ-M05 技术到量产 | 长期路线 → 工程实现、产能与良率 → 当期可相信的兑现程度 | 样本内支持；仓位及过渡方案分支各只有局部案例 |
| HJ-M06 更新判断 | 新财报或现金流约束 → 公开更正 → 改变选择 | 候选；两次明确完整案例不足以证明系统性习惯 |

方法卡的条件分支属于跨案例归纳；不是本人在每次分析时逐项执行的固定程序。详见 [Herman 方法卡](herman-jin-methods.jsonl)。

### Serenity

| 方法 | 典型路径 | 本轮判断 |
|---|---|---|
| SR-M01 需求向上游传递 | 支出/采购 → 生产依赖 → 材料与设备瓶颈 → 定价与利润落点 | 样本内支持；最上游不自动等于收益最多 |
| SR-M02 业务与融资 | 付款方 → 可比业务经济性 → 预付款/债务/稀释 → 现有股东收益 | 样本内支持；好经营前景仍可伴随差融资条件 |
| SR-M03 对应关系与阶段 | 公司实际产品/收入模式 → 消息或指标是否适用 → 认证、量产、收入处于哪一步 | 样本内支持；不同分支的证据强度不同 |
| SR-M04 前瞻经营量级 | 未来盈利或产能量级 → 与价格、市值比较 → 重估或回撤判断 | 样本内支持；统一会计口径等完整核验纪律属于本轮建议补上的检查 |
| SR-M05 隐藏客户关系 | 已知的相邻关系 → 推测未披露的完整关系 → 等待直接证据 | 候选；两个案例，不能称已可靠识别隐藏订单 |
| SR-M06 供应控制与定价 | 稀缺位置 → 替代与控制权 → 是否真正提价或锁供给 | 候选；两个案例，包含未发生的假设情景 |

详见 [Serenity 方法卡](serenity-methods.jsonl)。公司关系、技术条件、盈利估计的真实性在本轮均未做独立财务或产业审计。

## 3. 两人的可比处与分歧

以下“差异”是样本中的关注点或假设差异；日期、标的和条件不完全相同时，不把它写成正面交锋。

| 同一个研究问题 | Herman 的样本回答方式 | Serenity 的样本回答方式 | 可作出的比较 |
|---|---|---|---|
| AI 支出还能否继续？ | 看使用增长、云厂需求、收入与融资的不同层次；会随现金流约束改变公司选择 | 看付款方、可比成本结构、现金缓冲及钱转移到哪些供应商 | 都关注需求与资金，但切入层级不同；不能概括为一人只看增长、另一人只看现金 |
| 缺货能否变成股东收益？ | 看谁有实际交付能力、哪层难扩产、总包与器件厂议价差异 | 沿生产链映射后，再查收入模式、提价选择和融资稀释 | 共识较强：产业受益到股东受益之间还有具体条件 |
| 存储利润应该怎样定价？ | 多次强调商品涨价、周期和预期，明确区分 DDR/HBM；提过 PS，也承认可能低估需求 | 引用前瞻 P/E、利润和价格预期，认为涨价或回撤后仍应回到经营量级 | 这是较清楚的框架差异：对利润持续性的看法和估值口径不同；本轮不能裁定谁对 |
| CPO/硅光有前途，现在就能兑现吗？ | 检查架构更改、产能良率、延期与过渡方案；对不确定方案限制承诺 | 区分送样、认证、投产时间与产能测算；明确部分技术还早 | 共同重视阶段，不能仅凭技术方向标签推断他们观点相反 |
| 看好业务但融资变差怎么办？ | ORCL 案例中公开改变选择，并承认股价仍可能继续上涨 | IREN 重新评价扩张资金路径；AAOI 经营可能好但 ATM 使其难支持 | 两人都出现“公司前景与当前参与条件分开”的证据，不能把谨慎直接记成做空 |

## 4. 三条必须保留的变化

### 4.1 Herman：融资问题一直存在，后来改变了具体选择

2026-02-02 已谈融资收紧可能迫使资本开支下降（HJ-004）。02-08 又以推理毛利、收入增长与融资预算支持继续投入（HJ-005）。05-10 重读财报后更正投入比较，仍看 Oracle 建设转收入（HJ-006）。06-10/11 则明确称 ORCL 认错离场，把持续融资与现金收付失衡作为约束（HJ-007）。

因此，准确的描述是“融资约束在其选择中的权重和具体判断发生变化”。没有证据将它写成六月才第一次发现融资风险，也没有完整同期口径来解释全部变化。

### 4.2 Herman：光模块扩产难度的说法还没有闭合

2025-12-30、2026-01-06 将光模块描述为较易扩产（HJ-011/019）；2026-05-19 更强调光通信多环节扩产与迭代同时受限，并承认可能低估存储需求（HJ-022）。

器件、技术代际或市场条件可能有差异，但本轮没有找到本人逐项说明。保留张力，不能替他补出一个已证实的改口理由。

### 4.3 Serenity：业务能力和原股东收益分别更新

2025-11-30 的统一成本比较承认 IREN 自有设施优势，以及软件层做好后改变排序的可能（SR-003）。2026-03-05 明确说原先“colo + 自由现金流支持 GPU 扩张”的论点已实质改变，增加执行不确定性和稀释（SR-006）。07-17 对软件收购改善能力作正面评价，但仍保留 SBC 和融资约束（SR-008）。08-21 在 AAOI 上再次将经营前景与股权融资分开（SR-027）。

这些是不同变量分别更新的证据，不宜压成“永久看空某公司”或“任何融资都反对”。

## 6. 接下来如何用

这是一套可查询的研究材料。使用时可以按下面顺序提出问题；以下工作顺序是本轮分析者的组合建议，不是两人共同发布的策略：

1. 明确公司、主题、日期和分析期限。
2. 从案例库查到支持与反对的原文，先读连续上下文。
3. 用需求、供给、现金流、收益传导、估值、商业化阶段这些维度分别检查。
4. 只调用有适用案例的方法卡。缺数据时列出待查项；没有本人原话的新推演明确写成“按已归纳方法推演”。
5. 更新观点时间线，保留旧结论和变更理由，不把历史表态覆盖成现在的看法。

扩展到全量前，优先处理三个缺口：Serenity 长帖与图片的完整性；两人的失败或撤回案例；同一对象、同一日期、相同数据口径的比较。后续检验先冻结规则，再使用未参与归纳的新材料。本轮未做盲测、收益回测或投资能力排名。
