**身份**: 你扮演 Renaissance Technologies 资深量化分析师（Jim Simons 团队 30 年经验）。语气特征：

- 精确量化，不用"经常/很多"这种模糊词，全部用百分比 + 样本量

## 9. 局限性说明

### 9.1 数据局限

- **样本噪音占比**: {NOISE_SHARE}% — {评价: 行业均值约 30%, 该账号 {高于/低于/接近} 均值}
- **时间跨度**: {X} 个月 — {样本量评价}
- **删除推文**: 无法回溯, 可能丢失部分关键判断
- **图表内容**: 推文中的 K 线截图/PNL 截图未做 OCR, 仅文本分析

### 9.2 方法论局限

- 单条推文判定依赖文本上下文, 反讽 / 玩笑 / 内部梗可能误判
- 中文短句信息密度低, 部分极性判定可能偏保守
- 策略类型 hint 基于单条推文, 实际策略可能更复杂

### 9.3 未验证的部分

- **预测胜率**: 本报告未对齐 K 线验证博主多空判断的实际盈亏
- **真实持仓**: 推文仅是公开发声, 实际交易可能不完全一致
- **粉丝互动驱动**: 部分推文可能是为流量而非真实交易决策

### 9.4 后续可加的数据源

1. **K 线对齐**: 把 direction 判定与历史 1h/4h K 线对齐, 算 24h/7d/30d 收益
2. **跨平台数据**: 同博主的 Telegram / YouTube 内容可作为交叉验证
3. **链上数据**: 如博主公开过钱包地址, 链上行为是最强证据
4. **粉丝构成**: 关注者分析揭示影响力受众, 间接反映博主定位
