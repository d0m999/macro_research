## 9. 局限性说明

### 9.1 数据局限

- **样本噪音占比**: 31.8% — 行业均值约 30%, 该账号接近均值。但 noise 中含大量 reply guy 互动, 实际信息密度更低
- **时间跨度**: 28 个月 — 跨完整熊牛切换, 样本充分
- **删除推文**: 无法回溯, 怀疑历史有删除大额亏损推文的可能
- **图表内容**: 4,238 条推文中含 ~1,200 条带图, 图内容 (K 线截图/PNL 截图) 未做 OCR, 仅文本分析

### 9.2 方法论局限

- 单条推文判定依赖文本上下文, "100x SHORT YOLO" 类推文反讽 / 玩笑可能误判为真实交易意图
- 该账号语气夸张, 部分极性判定可能因夸张修辞而高估
- 策略类型 hint 基于单条推文, 实际策略可能更复杂或根本不存在系统化策略

### 9.3 未验证的部分

- **预测胜率**: 154 条价格目标预测未对齐 K 线验证
- **真实持仓**: "100x leverage" / "all in" 等表达**无法**从公开推文确认是否真实交易
- **粉丝互动驱动**: 互动量 Top 10% 的推文情绪强度显著高于均值 (polarity std 0.78 vs 0.62), 暗示**部分推文是流量驱动而非交易决策**

### 9.4 后续可加的数据源

1. **K 线对齐**: 把 154 条价格目标预测对齐 BTC/ETH/SOL 历史 1h K 线, 算预测胜率
2. **跨平台数据**: 该博主 YouTube / Twitch 内容可作为交叉验证
3. **粉丝构成**: 关注者分析揭示影响力受众 (散户/机构/同业 KOL)
4. **删除推文恢复**: Wayback Machine 或第三方推文存档 (如 ArchiveTeam) 可补全历史

## 10. 综合画像 (Renaissance Tech 风格量化总结)

该账号呈现一个**高情绪驱动、高杠杆话术、低纪律的加密 KOL**典型分布特征, 非系统化交易者。

- **方向偏好**: BTC 主导 (38%), 多空比 2.4x 偏多, 长尾标的 152 个反映 meme 投机驱动。Meme 类 (PEPE/DOGE) 方向 skew +0.55+ 显著极端
- **风险敞口**: 杠杆中位 10x + 止损提及率 10% — 形成"高杠杆 + 低纪律"组合, Risk-adjusted 评级**显著负向**。Heavy + All-in 占比 46% 在加密 KOL 样本中排前 10%
- **策略稳定性**: 主风格在 5 个半年窗口内变化 3 次 (swing → macro → scalping → scalping → macro), 显示**风格随市场叙事漂移**, 缺乏稳定方法论。Scalping 24% 占首位但与 long-term 17% 并存, 反映言行分离
- **情绪噪音**: polarity std 0.62 高于行业均值 (~0.45), FOMO 占比 28% 是均值的 1.9x。情绪与价格相关系数 r=0.71 显示**反应型情绪而非领先信号**
