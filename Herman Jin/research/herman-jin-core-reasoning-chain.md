## 一句话概括

Herman Jin 的推理不是"预测宏观→选股票"，而是把一个产业判断同时放进**三个时钟**里校准：宏观政策时钟（关税/财政/美联储）、产业供需时钟（token 需求 → CAPEX → 瓶颈）、市场交易时钟（仓位/波动率/CTA）。他的 alpha 几乎全部来自第二个时钟，错误主要来自对第一个时钟的权重和时点。

## 一、底层框架：三层时钟

1. **宏观层（政策与利率）**：2025 年初的基线是"政策转变之年"——关税、减支、移民三尾险 + 美元长端双强 + 财政扩张推高长端利率。这一层负责判断"底线有多高、尾险有多大"，决定总仓位和战术撤退窗口，但不决定买什么。
2. **产业层（AI 供需）**：这是他真正花力气的层。token 需求被他拆成三个相乘的函数——**使用次数增长 × 单次调用 token 数增长 × 单位 token 价格下降**——三个都指向总算力需求指数上升，而供给侧（TSMC 先进制程、先进封装、HBM）只能线性扩张 → 结构性缺货。
3. **交易层（仓位与拥挤度）**：波动率下降 → CTA/Vol-target 系统性买盘 → 趋势自我强化但也累积风险；反之拥挤的去杠杆会引发 30–50% 回撤。这一层负责"什么时候会被打脸"，把产业方向翻译成仓位纪律。

## 二、主干推理链：AI 算力链（他的核心贡献）

```text
人的行为变化（人只会更懒，搜索/网页访问转化为 AI 调用）
  → 调用次数非线性增长；每次调用背后消耗大量 token
  → token 使用量 = 指数函数（用量 × 单次token × 降价，三函数相乘）
  → Hyperscaler + 国家级 CAPEX 扩张
  → 供给侧只有 TSMC 能做先进制程，线性扩产；AP（先进封装）成为最终 gatekeeper
  → 产多少卖多少的卖方市场（"只要有片就给用掉"，AMD 困境反转即证据）
  → 缺货沿产业链轮动：存储 → 光模块 → CPU（"炒货逻辑"：先涨价的先补产能，
     补完炒下一个，扩产难度从右往左递增）
  → 涨价 + 产能转移（美光把手机排产转数据中心）→ 利润率与 EPS 弹性
  → 可投资映射：SMH/TSM/NVDA/AMD → MU/WDC/STX → COHR/LITE → INTC（CPU 缺货）
```

2025-12-30 的关键升级是 **Agent 数据生成机制**：传统软件是"做好数据放网上大家只读"，AI Agent 是每次调用都**生成并保存新数据** → 分布式存储需求"天亮级别" → 存储必须配 CPU 读取处理 → 存储/CPU 是串联瓶颈，CPU 缺货是"市场尚未意识到的预期差"。

配套选股逻辑是**预期差而非景气度**：他明确说光模块、存储"大家都知道缺货、没有预期差"，而 GPU/CPU 因为市场在争论"NVDA 还是 TPU 胜出"反而预期差最大——"不是 TPU 赢还是 GPU 赢，是他们都赢"。

## 三、风险链：他给 AI 主线主动装的"保险丝"

同一条主线的失效条件被他逐期升级：

- 2025-02：估值打满 + 2026 增速/毛利不确定 → 战术减仓窗口（长期叙事不变）。
- 2025-11：泡沫争论 → 他的判别标准是"AI 从早期就在赚钱"（广告推荐、效率、利润率），不是纯概念融资，故回调是买点。
- 2026-06：升级为系统性警示——"罩门"是 Anthropic/OpenAI 的收入增速，用 P2P 类比，预告年底至明年初较大调整。
- 2026-07/08：把尾部风险定位到**资金链**——Hyperscaler CDS、融资成本、"缺花 token 的钱"；同时用**卡折旧周期变长**（旧卡仍服役、二手价坚挺）反证现金流风险被高估。

## 四、推理方法上的四个习惯

1. **长期方向与短期仓位永远分开表述**。AI 是"工业革命级"与"3–6 月战术退出"并存不是矛盾，是他框架的标配。验证他的观点必须绑定期限。
2. **瓶颈/最短木板思维**（"水桶理论"的产业链版）：钱涌向全链时，先找扩产最慢、涨价最先的环节；产能可扩性从易到难 = 轮动顺序。
3. **永远先写反方再下结论**。Oracle 案例他完整陈述了高杠杆+客户信用集中+自买自销的空头链再否定；INTC 列了执行条件（18A 良率、客户、管理层）。这使他错了也能定位是哪一环权重错了。
4. **数据验证偏好"草根供给证据"**：美光排产转移、CPU 涨价次数、存储条被扫货、GPT 日请求 10 亿——他更信产业链一线缺货信号，相对不信问卷和一致预期。
