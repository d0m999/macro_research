## 2. 已做的加工

| 项 | 做法 |
|---|---|
| 碎片段合并 | 原文 p50 仅 10 字符；按 `manifest.chapters[].label` 合并相邻同主题后，块内累积到 ~240 字符成块，不跨主题段、不跨期 |
| 非《市场概述》系列包 | 照常并入所属月份文件，**但不使用章节标签**（其章节是管线机械等分）→ 改按**固定 15 分钟时间窗**分块，并在文件头与本期小节内声明。当前名单：`market-overview-2026-05-14`（脚本常量 `TIME_WINDOW_PKGS`） |
| 分段归属 | 每段**唯一归属**一个段（按段起点二分）——修正了早期用 ±0.6s 容差导致章节边界段**被重复计入**的问题（曾影响 106 段 / 1,146 字符） |
| 行号锚点 | 每块前缀 `[L120-L128]` = 该期 `transcript.jsonl` 物理行号（1-based）；X 与 research 同理 |
| 繁→简 | 全量 `zhconv` → `zh-cn`（原文不动） |
| 剔噪 | 视频：空白/纯表情段不落盘；X：纯表情/纯标点/4 字以下（并集 441 条 + 6 条）、重复正文剔除 |
| 表情保留 | 含 emoji 但带文字的 **511 条（7.1%）原样保留**（😂162/🤣59/👍50）——表情承载语气，且占比小（用户 2026-09-21 决策：不剥离） |
| 上下文头 | 每个文件头部写明源路径、覆盖范围、行号约定、加工程度、ASR 局限 |
| 异名对照 | 视频/外访文件头内联「已修 ASR 异名对照」（Abago=Avago / Babao=Marvell / 狗门=Goldman Sachs …），用于对齐残留误识 |
| 去重 | X 重复正文只留首条（`in_reply_to_post_id` 恒空，无法还原上下文） |

## 4. 上传顺序建议

1. **32 个一次全传**。清洗已于 2026-09-20 定格（人工听音不做，见 §2），没有等待理由
2. 日后新增一期：重跑脚本 → **只重传变化的那一件**（新增月份文件或 `hj-video-YYYY-MM.md`，最大 64,692 字符，几秒钟）
3. **全部放进同一个 notebook**：notebook 是孤岛，跨期对比只能在同一库内做
