# 13FInsight：已确认上游、字段与使用边界

核验日期：2026-10-07。范围：公开页面、正常页面操作及少量 SEC 原始申报样本；未登录、未调用鉴权 API、未检查后台实现。本文记录来源与口径，不提供交易建议，不代表完整供应商审计。

## 与现有集合的关系

- 路由入口仍为 [data-sources.jsonl](../../.agents/data-sources.jsonl)，合规状态仍由 [PUBLIC-SOURCE-POLICY.md](../../.agents/PUBLIC-SOURCE-POLICY.md) 定义。
- **只扩充既有 `sec-edgar`**：保留 ID 与固定字段顺序，分类从 `filings` 增补 `institutional`、`insider`；SEC 是已确认的原始申报机构，不为每个表单重复创建供应商。
- 13FInsight 是聚合、标准化及解释层。[产品说明](https://13finsight.com/llms.txt)列有免费与订阅档、历史深度和持有人数量限制、登录工具及鉴权 API。它不满足登记表“仅收完全免费来源”的整个平台口径，**因此不新增 free 来源行**。本文中的公开入口是核验线索，不是绕过登记表的新路由。
- 公司公告回到既有 `company-ir-official`；新闻只作文章级补充，不能因样本外链就把媒体登记为平台供应商。无法合法访问或回源的输入仍标 `SOURCE_UNAVAILABLE`。
- 此前清单的 **36 是核查项数，不是数据供应商数**。能够确认的是 SEC EDGAR 一个具名原始申报机构、13F / 13D-G / Form 4 三个家族；补充行情及证券信息的供应商数量未知。

## 原始申报与字段

以下是回源时应保留的字段，不是声称每个字段都在 13FInsight 页面公开展示，也不是其真实数据库 schema。

| 家族与入口 | 原始字段 / 审计键 | 站方覆盖声明 | 必须保留的限制 |
|---|---|---|---|
| [13F](https://13finsight.com/filings) → `sec-edgar` | 管理人 CIK、accession、表单、提交/接受时间、报告期、修订类型；issuer/class、CUSIP、金额及单位、股数/本金、SH/PRN、PUT/CALL、投资裁量/其他管理人、投票权 | 13F-HR 从 1999 Q2 起；13F-NT、13F-HR/A 已列入公开方法说明 | NT 是通知，不是零持仓；重述与追加不同。站方 13F-NT/A 覆盖未确认，不代表 SEC 无该表单 |
| [13D/G](https://13finsight.com/filings/activists) → `sec-edgar` | 发行人/报告人 CIK、accession、表单及修订、事件日/申报日；逐个 reporting person、证券类别、CUSIP、受益股数/%、单独/共享投票与处置权、股本分母及脚注、资金来源/目的/协议 | 1994 Q1 起；13D、13D/A、13G、13G/A 在核查界面可见 | 联合报告人可重叠，不能逐人求和；受益比例不是组合权重；13D 不自动代表收购，13G 也不全等于被动投资 |
| [Form 4](https://13finsight.com/insider) → `sec-edgar` | 发行人/报告人及职务、accession、交易日/申报日、证券类型、交易代码、取得/处置方向、数量、价格、直接/间接持有、脚注及关联事件 | 2003 Q3 起 | 交易行不等于文件数；价格是申报事件价格，不是实时行情。4/A 的站内覆盖未确认；无 10b5-1 标记不能推断自主交易 |

站方历史起点来自 [llms.txt](https://13finsight.com/llms.txt)，不是逐年完整性审计。该文件自标 2026-07-04 更新；套餐和 API 描述也可能滞后，应按实际页面重新确认。SEC 全文入口：[EDGAR](https://www.sec.gov/edgar/search/)。

## 处理层、派生层与未确认上游

| 层 | 已知内容 | 不应推定的内容 |
|---|---|---|
| 标准化 | 方法页自述修订重述替换、追加合并；CUSIP 大小写/补零、证券分类和机构类别过滤 | 未验证完整修订链、共享管理去重、缺报/保密处理、拆股/换股/CUSIP 变化、跨历史单位处理 |
| 证券补充 | llms.txt 自述 ticker、sector、market cap 来自 enrichment sources | 未具名供应商；不能猜 Yahoo / Polygon / FMP / Finnhub。OHLCV、复权、币种、时点、行业体系及授权来源未确认；CUSIP 映射供应商亦未知 |
| 持仓差分/权重 | 股数变化、报告市值变化、报告范围内权重和集中度可用原表复算 | 市值差不是净买入金额；报告总值变化不是收益率；期权标的价值不是实际资本投入。Latest 聚合可能混报告期，优先固定季度 |
| 机构汇总 | 公开说明有持有人、buyers/sellers、共识及组合聚合 | 样本覆盖、母子机构/共享管理去重、NET $ 算法及完整生产实现未验证；登录工具未实测 |
| WhaleScore | 有历史公开公式和分档说明 | 当前算法未确认；评分不是原始金融源，也不是收益率或预期回报 |
| AI / 编辑解释 | 站方将 Claude 问答和静态摘要描述为基于实体申报数据；审核是站方说明 | 模型版本、API 渠道、实际检索输入、prompt、逐句事实支持和现行审核流程未验证；不能把解释当独立原始证据 |
| 新闻 / 研究外链 | 少量文章出现公司 IR、Reuters、MedTech Dive、Nasdaq 外链，另有 Google News 选题自述 | 样本不证明授权供稿、采购关系、全量新闻数据库或完整供应商清单 |

原始事实回 SEC；独立计算用 `MODEL_DERIVED` 并保留公式/分母；站方公开说明与抽样复算必须分开标注。

## 关键局限及一手证据

1. **时间与覆盖。** 13F 是季末快照，申报可滞后 45 天，且不覆盖完整资产组合。用报告期、申报/接受日、观察日三套时间，历史研究按当时已公开版本截断；事后修订/解密不能倒填为当时可得信息。方法页称每 15 分钟轮询，部分活动页面宣传少于 5 分钟，本次没有测量端到端 SLA。[方法页](https://13finsight.com/about-data)、[活动入口](https://13finsight.com/filings)
2. **股数与市值方向可以相反。** Private Capital Advisors 的两期原表中，AAPL 股数少 483，但报告市值多 11,410,099 美元；LLY 多 115 股，市值少 17,290,785 美元。仅支持两期报告变化，不证明交易金额/成本。[前期原表](https://www.sec.gov/Archives/edgar/data/1350780/000135078026000003/xslForm13F_X02/inftable.xml)、[后期原表](https://www.sec.gov/Archives/edgar/data/1350780/000135078026000004/xslForm13F_X02/inftable.xml)、[站内管理人页](https://13finsight.com/filers/private-capital-advisors-inc-0001350780)
3. **报告人归属。** 2026-10-07 样本中，站内把 Cross Ocean Partners Management LP 关联约 8.4M 股/7.9%；同份原报该组数字属于 GSS Master Fund LP，Management LP 为 22,495,104 股/21.3%。应逐报告人复核，不能仅复算比例；不推断后台错误原因或全站错误率。[站内列表](https://13finsight.com/filings/activists)、[原报 reporting person 与权益节点](https://www.sec.gov/Archives/edgar/data/1738827/000121390026107356/xslSCHEDULE_13D_X02/primary_doc.xml)
4. **交易含义。** LEVY ANTON J / WBD 样本的 585,000 × 31.0167 ≈ 18.14M 美元可复算，但原报脚注说明是合并现金对价，不能据站内“公开市场卖出”标签认定自主看空。交易代码与取得/处置方向是不同字段；P/S 也包含私下交易，必须看脚注。[站内列表](https://13finsight.com/insider)、[原报及脚注 1/2](https://www.sec.gov/Archives/edgar/data/1396681/000139668126000006/xslF345X06/wk-form4_1791333125.xml)
5. **WhaleScore 版本冲突。** [旧文](https://13finsight.com/learn/how-to-read-whale-scores-institutional-investor-quality)披露规模/集中度/申报记录按 40%/35%/25% 加权；[六月文](https://13finsight.com/learn/whale-score-institutional-investor-quality-explained)称精确权重不公开；[后续更新文](https://13finsight.com/learn/how-to-read-whale-scores-quality-metrics)使用不同维度并讨论历史表现。因此不能说“从未披露公式”，也不能声称旧公式就是当前实现。
6. **新闻引用本身也需校验。** [Micron 文章](https://13finsight.com/news/micron-ceo-mehrotra-sold-27m-ai-memory-rally)的 FY2025 标签对应外链在核查时落到 [2017 年 IR 公告](https://investors.micron.com/news/press-release/2017/Micron-Technology-Inc--Reports-Results-for-The-Fourth-Quarter-and-Full-Year-of-2017-09-26-2017/default.aspx)。链接存在不等于年份与主张吻合。

## 核验状态与复用检查

- 同日公开页面/浏览器样本核验支持上述观察；样本是局部、可变的页面状态，不能推广为完整覆盖或稳定可用性。
- 本次仓库整合重开 `about-data` 与 `llms.txt` 成功；`pricing` 在文本读取工具中无正文。重开上述后期 13F、13D 与 Form 4 SEC 样本时，文本工具均返回不可访问；没有绕过限制，也不将此次重开写成成功。样本观察来自同日早先公开浏览器核验。
- `sec-edgar.last_checked` 保留原值，避免一次专题整合被误读为 SEC 所有通道重新验证；本次日期、路径和失败边界记在本文及该条 `limitations`。
- 复用时：检查页面可达性与免费范围 → 固定期间/对象/表单 → SEC 原报绑定字段 → 校验单位、修订与去重 → 复算指标 → 单列未知项。任何步骤缺失，保留缺失状态，不以 AI 文案、站方宣传数量或不明行情替代。
