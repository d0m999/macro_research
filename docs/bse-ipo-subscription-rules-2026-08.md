# 北交所股票公开发行网上打新规则研究

资料截点：2026-08-26

## 1. 研究范围与结论

本文所称“北交所打新”，特指“向不特定合格投资者公开发行股票并在北京证券交易所上市”的网上申购，不包括上市公司再融资、配股、可转债或战略配售。

普通合格投资者参与北交所网上打新的核心机制是：先开通北交所交易权限；申购不要求持有股票市值，但需要以可用现金全额缴付申购资金；申购单位为100股；超额申购时按比例配售，比例计算后的不足100股部分再按“申购数量优先、数量相同时间优先”依次配售100股。因此，它不是沪深市场常见的市值配售，也不是单纯抽签。

## 2. 现行规则要点

| 事项 | 现行规则 | 实务含义 | 依据 |
| --- | --- | --- | --- |
| 参与资格 | 个人投资者申请开通权限前20个交易日，证券账户和资金账户资产日均不低于50万元（不含融资融券融入的资金和证券），且参与证券交易24个月以上。已开通科创板交易权限的个人投资者申请开通北交所权限时，不适用上述资产和交易年限核验。机构投资者按法律法规和业务规则执行。 | “50万元”是通常的权限门槛，不是每次打新的现金门槛。开通权限还要完成风险揭示等券商适当性流程。 | [A] |
| 市值要求 | 证监会投资者教育口径明确，北交所新股申购无市值要求。 | 不需要为了获得申购资格而预先持有北交所或其他市场股票；但不等于可以用股票市值代替申购现金。 | [C] |
| 申购资金 | 参与申购前，应在证券公司资金账户存入足额申购资金；申购按发行价格计算，申报经交易主机确认后不得撤销。 | 申购股数 × 发行价，是申购时需要准备的资金上限。债券、股票等资产的市值不会自动变成可用现金。 | [B] |
| 申购单位与上限 | 每个申购单位为100股，申购数量必须是100股的整数倍；一般不得超过网上初始发行量的5%，且不得超过9999.99万股，发行公告或北交所另有调整的除外。 | 计算个人上限时要看当次发行公告中的“网上初始发行量”，不能直接拿总发行量计算。 | [B]、[E] |
| 申购时间 | 申购日（T日）9:15–11:30、13:00–15:00，通过证券公司委托。 | 具体申购代码、发行价、网上发行量和日期以该只股票的发行公告为准。 | [B]、[E] |
| 账户与重复申报 | 同一投资者对同一只股票使用多个证券账户，或使用同一证券账户多次申购，以第一笔申购为准；网上投资者应自主表达申购意向，证券公司不得接受全权委托代申购。 | 不要用多个账户拆单，也不要重复下单试图增加额度。 | [B] |
| 配售方式 | 有效申购总量大于网上发行数量时，先按“网上发行数量 ÷ 有效申购总量”计算各投资者配售数量；不足100股的零碎部分汇总后，按申购数量优先、数量相同时间优先，依次配售100股，直至无剩余。 | 申购数量越大，通常越有利于获得零碎配售；同一申购数量下，申报时间更早者优先。 | [D] |
| 资金结算 | T日日终按清算数据冻结申购资金；T+1日完成申购资金交收。无效申购处理后，T+1日日终扣除获配部分对应资金并解冻余额；证券公司应于T+2日向投资者推送配售结果。 | 资金不是永久冻结；但在申购和结算期间必须保证资金真实可用。冻结资金利息按规则划入证券投资者保护基金，不返还个人。 | [B] |
| 资金不足后果 | 因申购资金不足导致申购无效的，相关责任由投资者承担；网上投资者自结算参与人最近一次申报其无效申购信息次日起180个自然日（含次日）内，不得使用名下任何证券账户参与股票公开发行网上申购。 | “少放一点资金”不是低成本试错，可能导致部分申购无效并触发六个月限制。 | [B] |

上述权限门槛来自《北京证券交易所投资者适当性管理办法》；申购单位、申购上限、交易时段、账户规则、资金交收和资金不足处理来自北交所与中国结算联合发布的《北京证券交易所股票向不特定合格投资者公开发行与承销业务实施细则》；无市值要求来自证监会投资者教育页面。见文末来源。

## 3. T日流程

| 时间 | 发生事项 | 投资者关注点 |
| --- | --- | --- |
| T-2及以前 | 主承销商披露发行公告、申购信息和发行安排；若为询价发行，价格先经网下询价形成。 | 先看发行价、网上初始发行量、申购上限、是否有战略配售或超额配售选择权。 |
| T日 | 9:15–11:30、13:00–15:00网上申购；T日日终按清算数据冻结资金。 | 账户权限、申购代码、现金余额和申报数量必须同时正确；申报确认后不能撤销。 |
| T+1日 | 中国结算北京分公司组织申购资金交收；资金不足部分作无效申购；T+1日日终扣除获配资金、解冻余额。 | 结算日仍需保证资金足额，不能把“申购时下单成功”理解为已经完成缴款。 |
| T+2日 | 证券公司向投资者推送配售结果；股份登记按发行人和中国结算的配售结果办理。 | 核对获配股数、扣款金额和账户入账；若发行中止或失败，按公告办理资金返还。 |

## 4. 资金与获配计算

设：

- `P` = 发行价；
- `Q` = 申购股数，且为100股整数倍；
- `A` = 网上初始发行量；
- `S` = 全部有效网上申购股数。

申购前需要准备的资金上限为：

```text
Q × P
```

若 `S > A`，比例配售的未取整部分可先按下式理解：

```text
个人基础配售股数 ≈ Q × A ÷ S
```

随后，对不足100股的零碎部分进行汇总，并按“申购数量优先、同量时间优先”逐个配售100股。最终实际扣款按获配股数计算，而不是按全部申购股数永久扣款；未获配对应的冻结余额按规则解冻。

例如，发行价为10元、个人申购100,000股，申购前应准备的资金上限是100万元；实际获配多少股，取决于网上发行量、全市场有效申购总量及零碎配售顺序。

## 5. 发行公告必须逐只确认的内容

规则给出的是通用框架，实际参与某一只新股前仍须阅读该股的《向不特定合格投资者公开发行股票并在北京证券交易所上市发行公告》和《投资风险特别公告》，至少确认：

1. 发行方式：直接定价、网上竞价还是网下询价；
2. 发行价格、发行数量和网上初始发行量；
3. 申购代码、T日、申购上限和是否包含超额配售选择权部分；
4. 战略配售数量、限售期、网上网下回拨安排和中止发行条件；
5. 发行人的盈利、估值、流动性和上市后价格波动风险。

北交所现行《证券发行与承销管理细则》允许直接定价、合格投资者网上竞价或网下询价等定价方式；发行公告还应披露申购缴款要求、配售原则、发行时间安排和余股处理等事项。2025年修订主要优化了战略配售等发行承销安排，不改变普通网上投资者上述“权限+现金+100股单位+比例配售”的基本理解。

## 6. 资金安排的边界

“资产日均50万元”与“申购现金足额”是两个不同概念：

- 开通权限时，合格资产口径可以包含符合指南规定的股票、基金、债券等证券资产。[F]
- 实际打新时，必须把可用资金存入资金账户，债券或股票市值不能直接抵扣申购款；
- 如需要从债券资产变现，必须考虑卖出、到期兑付、质押式回购或其他券商允许的资金调度路径，以及到账时点和券商风控限制。

具体可用资金、融资融券账户能否用于某项申购、资金到账截止时间和券商委托限制，还要以开户券商的业务规则为准。

## 7. 多只新股重叠与动态资金池

如果一个期限内有多只新股，不能只按“申购日”做一张收益表，而应把每只新股作为独立的资金占用对象：

```text
A股：T_A ──申购资金冻结── T_A+1 ──保留实际获配成本── L_A卖出
B股：        T_B ──申购资金冻结── T_B+1 ──保留实际获配成本── L_B卖出
C股：                T_C ──申购资金冻结── T_C+1 ──保留实际获配成本── L_C卖出
```

设：

- `C_t` = 日期 `t` 的可用现金；
- `D_i = P_i × Q_i` = 第 `i` 只新股在申购日需要冻结的申购金额；
- `A_i = P_i × q_i` = T+1实际获配后继续占用的资金；
- `V_i` = 上市首日卖出并完成结算后回到资金池的净卖出款；
- `R_t` = 逆回购本金及其到期收益。

对每只新股按以下状态转移处理：

```text
T_i：       C -= D_i；申购冻结资金 += D_i
T_i+1：     释放 D_i - A_i；待上市持仓成本 += A_i
上市卖出：  待上市持仓成本 -= A_i；结算后 C += V_i
空白期间：  仅用真正可用的 C_t 做逆回购
```

北交所现行实施细则规定申购资金在T日日终冻结、T+1日完成申购资金交收；北交所也明确流程优化后冻结时间由3个交易日缩短为2个交易日。因此，在T日申购时，必须按全部申购金额 `D_i` 预留现金，不能提前按预计获配金额 `A_i` 计算可用资金。[B][G]

若多只股票在同一个T日申购，所有申购金额必须同时满足：

```text
Σ D_i ≤ C_T - B
```

其中 `B` 是不参与申购的安全缓冲。若不满足，就不能假设每只股票都申购100万元，而应按预先确定的权重缩小申购数量、按优先级申购或放弃部分标的。申购数量仍须满足每只股票的100股整数倍和该股发行公告规定的上限。

相邻申购日尤其需要按日内顺序处理：

| 两只新股的关系 | 后一只申购可否使用前一只资金 |
| --- | --- |
| `T_B = T_A` | 不能使用A的申购冻结资金；两只申购金额合计必须在T日可用现金内覆盖 |
| `T_B = T_A+1` | 保守模型中不能使用A的超额解冻款，因为A的余额通常要到T+1日日终才解冻 |
| `T_B >= T_A+2` | 可使用A已解冻且经券商确认可用的余额 |
| A在B的申购日上市并卖出 | 不提前计入A的卖出回款；按结算后实际可用时间入账 |

这个日内顺序是资金模型最容易出错的地方：不能看到“前一只新股预计只获配少量资金”，就提前把其余申购款拿去申购后一只股票。申购资金的冻结和T+1交收安排见[B]和[G]。

推荐的基础处理方式是：

1. 如果可用现金足够覆盖所有标的的申购上限，则各标的按各自上限申购；
2. 如果现金不足，则将 `C_T - B` 按固定权重分配给当日标的，默认可采用等额现金分配，再按100股向下取整；
3. 只有在建立了发行价、预计配售比例、预期首日收益和资金占用天数模型后，才使用“预期净收益/资金占用天数”排序，否则不临时凭主观判断集中押注一只股票；
4. 不把尚未解冻的申购资金、尚未卖出的获配股票成本或尚未完成结算的卖出款重复计入可用现金。

上市日期 `L_i` 应以该股票后续上市公告或交易提示中的实际日期为准，不在模型中简单写死为某个固定的 `T+N`。如果A股尚未上市，B股已经进入申购，B股只能使用扣除A股待上市占用资金后的可用现金；A股卖出回款应在券商和结算确认可用后才重新进入资金池。

复利也应在这个动态余额上计算：逆回购到期后将本金和利息一起作为下一期本金；新股卖出后的净卖出款（包括已实现的打新利润）进入 `C_t`，从下一次逆回购或申购开始扩大资金基数。因而不能用“100万元 × 全年逆回购年化收益率”直接估算全年收益，必须逐日扣除冻结日、待上市持仓占用日和结算等待日。
